# 制作技能包（shuohao-skills）

5 个配套技能。每个文件夹 = 一个独立技能，**零依赖、零 API key**，需要 node ≥ 18。

| 技能 | 干什么 |
|---|---|
| `novel-outline` | 把故事整理成大纲五件套：改编说明 / 人物表 / 爽点表 / 分集梗概 / 资产清单 |
| `novel-script` | 写剧本：场次 + 节拍流（动作与台词交替），逐集时长按语速折算 |
| `novel-characters` | 角色设定集：人物画像 / 形象提示词 / 音色提示词 / 角色设定图 |
| `novel-art` | 美术设定集（场景 + 叙事道具）：一致性锚点、光照变体、空景提示词 |
| `novel-storyboard` | 分镜：段 → 分镜 → 分镜图（含提示词），export 一键出投产包 |

## 安装

**Claude Code**：
```bash
cp -r shuohao-skills/skills/* ~/.claude/skills/
```
（或运行 `bash shuohao-skills/scripts/install.sh --claude`）

**codex**：
```bash
cp -r shuohao-skills/skills/* ~/.codex/skills/
```
