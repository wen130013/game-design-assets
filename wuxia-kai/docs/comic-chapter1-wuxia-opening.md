## 二、开篇剧情流程（凯视角 · 分步）

1. **突然出现在镇外路边**：四下无人或少人，他环顾说出"这又是什么世界？"之类台词（老穿越者，不慌）；抬眼看见前方镇子轮廓/炊烟。
2. **进镇闲逛**：作为普通人直接沿路走进镇子（**不做夸张动作**），四处逛逛看市井。
3. **见招募告示**：逛到**六扇门**（用户定名 ✅）门口，见贴告示招捕快，上前看榜、应募。
4. **考核展示属性**：六扇门按常规考较（力气/筋骨/反应等），他**表现明显好于常人**——考官与围观者惊讶但不离谱；考官看出资质："不错，是个可教之才"→ 录用。
5. **入职发物**：发**官服** + **功法书**（书里含本世界修行基础，见 §七 设定展示设计）。

## 三、小镇设定

- 名字：⚠️ 占位。候选：**青柳镇 / 清河镇 / 石桥镇 / 白水镇**。
- 定位：离县城两三天脚程、有官道经过的县辖镇；行商、镖队、江湖人偶过。凯当捕快才有事可干。
- 人口感：几百户人家，市井气浓。

## 四、自然风景（环境层）

- **穿越林（镇外）**：大树成片杂林/竹林松林，落叶层、晨雾光柱。树=必需元素。
- **山（镇后）**：低山丘陵竹林松林，云雾山道（通什么 ⚠️）。

- **田/官道**：稻茬黄枯褐的秋冬田野；黄土官道、茶棚、凉亭。
