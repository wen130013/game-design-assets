## 一、这是什么

多世界修炼体系主线故事 · **第一部：武侠世界**。
主角**凯**（十几岁少年）突然出现在小镇外的官道上——他穿越过很多世界（且都记得），是一个不慌不忙的开朗少年。

**第一幕流程**：出现在镇外 → 进镇闲逛 → 见「六扇门」招捕快告示 → 应募 → 考核中展示出远超常人的资质 → 被考官看中（"不错，是个可教之才"）→ 录用，发官服 + 功法书。

**本幕只有凯一个人出场**，其他队友（智、重力、大虎、唐二、京城四少/六位、邪恶智/凯等，见 story-bible）全部不出场。

## 三、凯 · 固定外观描述（🔴 后续每一格生图都照抄这段，保证角色一致）

> 约十五六岁的清秀少年，黑发中长碎发（短发偏长、发梢到耳下颈侧、前额碎刘海），黑亮大眼睛带细腻高光，开朗阳光气质；身形清瘦但肩臂有薄肌肉；穿深灰褐色粗布短打（**干净整洁、无破损、无污渍**，窄袖、束布带），无武器无配饰。

⚠️ 服装注意：用户明确过"衣服不能破"——粗布=朴素，但必须干净整洁。
