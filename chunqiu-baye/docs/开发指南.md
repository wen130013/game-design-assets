# 春秋霸业 开发指南

> 本指南面向后续开发：**改地图、删省份、加省份、调渲染**。改动前先读这里。

---

## 1. 项目结构

```
/workspace
├── scripts/                     # 游戏 Lua 代码（唯一手写代码位置）
│   ├── main.lua                 # 入口（Start/Stop/主流程）
│   ├── config/GameConfig.lua    # 游戏配置（标题、版本等）
│   ├── core/GameState.lua       # 游戏状态、初始领地分配
│   ├── core/TimeSystem.lua      # 时间系统
│   ├── systems/                 # 经济/军事/外交系统
│   ├── ai/AIManager.lua         # AI
│   ├── events/EventManager.lua  # 事件
│   ├── save/SaveManager.lua     # 存档
│   ├── data/                    # ★ 地图数据
│   │   ├── world_provinces.json        # ★ 权威数据（编辑器保存到这里）
│   │   ├── GeneratedProvinces.lua      # 由 build_provinces.py 生成（运行时加载）
│   │   ├── Provinces.lua               # 数据加载器（require GeneratedProvinces，建索引）
│   │   ├── Geography.lua               # 地图几何常量（MAP_W=10800, MAP_H=6864 等）
│   │   └── Factions.lua                # 势力数据
│   ├── map/
│   │   ├── MapRenderer.lua      # ★ 地图渲染（NanoVG）+ 点击/hover + 编辑按键
│   │   ├── MapEditor.lua        # ★ 编辑工具（删除/合并/撤销/保存/历史）
│   │   └── SpatialIndex.lua     # 点击查询空间索引
│   └── ui/GameUI.lua            # 游戏内 UI
├── assets/image/                # 图片资源（运行时只用 world_map_base.png）
│   └── world_map_base.png       # 底图（由 gen_base_image.py 生成，不含边界线）
├── gen_world_map.py             # [工具] 从 GADM 原始数据生成初始省份 JSON
├── build_provinces.py           # [工具] 重建 id/邻接，输出 GeneratedProvinces.lua
├── gen_base_image.py            # [工具] 从省份数据生成底图 PNG
└── docs/开发指南.md             # 本指南
```

## 2. 数据流（最重要，先理解这个）

```
GADM 原始数据 (.json)
   │  首次建图
   ▼
gen_world_map.py ──────────────► scripts/data/world_provinces.json   （权威数据）
                                        │
                                        │  数据改动后跑（每次都要）
                                        ▼
                              build_provinces.py ──► scripts/data/GeneratedProvinces.lua
                                        │                          │
                                        │                          ▼
                                        │                运行时 require 加载
                                        ▼                         │
                              （MapEditor 运行时编辑/保存）        ▼
                                        │                 Provinces.lua（内存数据）
                                        ▼
                              保存 = 写回 world_provinces.json
```

**核心规则**：
- `world_provinces.json` 是**唯一权威数据源**，包含所有编辑结果。
- 运行时 Lua 加载的是 `GeneratedProvinces.lua`（由 build_provinces.py 生成）。
- **任何数据改动后**：`python3 build_provinces.py` → 重新构建 → 生效。
- **每次修改后必须重新构建**（MCP build 工具）。

### 省份字段说明

| 字段 | 类型 | 含义 |
|------|------|------|
| `id` | number | 省份 ID（build 时重排 1..N） |
| `name` | string | 名称（中文） |
| `center` | {x, y} | 名字显示位置（build 时用 shapely representative_point 保证在区块内） |
| `polygon` | {{x,y},...} | 边界多边形（逻辑坐标，build 时去尖刺/切角 + 合并精确并集） |
| `neighbors` | {id,...} | 邻接省份 ID（build 时自动重建） |
| `terrain` | string | 地形（平原/山地...） |
| `isOcean` | boolean | **已删除区块**（删除=变海洋，不再画边界） |
| `editorFilled` | boolean | **合并后的 target**（填米色盖住内部线；build 时用 shapely 精确并集重建多边形） |
| `suppressOceanCover` | boolean | **被合并吸收的省**（不显示海色覆盖，保持陆地色） |
| `absorbedBy` | number | **被谁吸收**（target 的 id；点击命中它也命中合并区块） |

## 3. 地图编辑工具（运行时改地图）

在游戏内按以下按键（小键盘）：

| 按键 | 功能 |
|------|------|
| 小键盘 **1** | 删除鼠标指向的区块 → 变海洋 |
| 小键盘 **2** | 进入/退出「合并选择」模式（点击区块选中/取消） |
| 小键盘 **3** | 合并选中的区块（≥2 个） |
| 小键盘 **4** | 进入/退出「涂抹选择」模式（按住左键滑动选中） |
| 小键盘 **5** | 撤销上一次操作（历史最多 50 条） |
| 小键盘 **6** | 按键帮助面板开关 |
| **S** | 保存编辑结果 → 写回 `world_provinces.json` |
| **ESC** | 退出编辑模式 |

**保存后**：
1. 按 S 保存（写 world_provinces.json）
2. 退出游戏，运行 `python3 build_provinces.py` 重新生成 Lua
3. 重新构建 → 新地图正式生效

> 注意：被合并的省保存为 `isOcean=true + suppressOceanCover=true`（不显示海色、不画线）；删除的省保存为 `isOcean=true`（显示海色）。

## 4. 修改/删除/增加省份

### 4.1 删除省份（推荐：编辑工具）
- 游戏内小键盘 1 删除 → S 保存 → build_provinces.py → 重新构建。
- 删除后该区块显示为海色（`isOcean=true`），不残留边界线。

### 4.2 合并省份（推荐：编辑工具）
- 小键盘 2/4 选择 → 小键盘 3 合并 → S 保存 → build 流程。
- 合并精度：`MapEditor.lua` 中 `unionPolys` 的 `GRID = 1000`（越大越精细越慢）。

### 4.3 直接改数据文件（手动）
编辑 `world_provinces.json` 中某个省：
- 改 `polygon` 顶点坐标（保持逻辑坐标范围 0~10800 × 0~6864）
- 改 `isOcean` / `editorFilled` / `suppressOceanCover` 标记
- 新增省：复制一条记录改 id/name/polygon
- 删除省：建议标记 `isOcean=true` 而非删除记录（保留历史数据）

然后：`python3 build_provinces.py` → 重新构建。

### 4.4 从 GADM 重新生成（大规模重建）
- 仅当需要全新数据源时运行 `gen_world_map.py`（会覆盖权威数据，慎用）。

## 5. 渲染流程（MapRenderer.lua）

绘制顺序（每帧）：

```
1. 底图           image/world_map_base.png（nvgCreateImage）
2. 海色覆盖层     isOcean 且非 suppressOceanCover → 填充海色（156,183,212）盖住删除区块
3. Pass B        省份填色（有主=派系色；editorFilled=米色；无主不填，露出底图）
4. Pass B2       省份边界线（isOcean 已被过滤；suppressOceanCover 不画线）
5. Pass C        交互高亮（hover 白描边 / 选中金描边，Chaikin 圆滑）
```

关键常量：`SEA_COLOR`（海/未占领底色）、`BORDER_ALPHA`（边界线透明度）、`HIGHLIGHT_*`（选中高亮色）。

- 点击检测：`getProvinceAtPoint()`（空间索引 → 全量扫描兜底，编辑后无需重建索引）
- 合并 target 优先命中：`editorFilled=true` 的省优先返回

## 6. Python 工具

| 工具 | 作用 | 何时运行 |
|------|------|---------|
| `gen_world_map.py` | 从 GADM 生成初始省份 JSON（中国地级市 + 世界省界） | 仅首次建图/彻底重建 |
| `build_provinces.py` | 重建 id/center/neighbors；**合并精确并集（shapely）**；**去尖刺/切角**；名字位置保证在区块内 | **每次数据改动后必跑** |
| `gen_base_image.py` | 生成底图 PNG（只画陆地色块，不画线） | 省份增删后重新生成底图 |

依赖：`pip install numpy opencv-python shapely pillow`（cv2）。

> build_provinces.py 还会生成 `screenshots/build_preview.png`（处理前红/处理后绿边界对比图），方便检查平滑效果。

## 7. 常见任务速查

| 想做什么 | 做法 |
|---------|------|
| 调整边界线颜色/粗细 | MapRenderer.lua Pass B2（颜色/线宽） |
| 调整底图 | 改 `gen_base_image.py` 后重新生成 |
| 改地图尺寸 | `Geography.lua` 的 MAP_W/MAP_H（注意与生成工具一致） |
| 增加新势力/国家 | `Factions.lua` |
| 调整经济/军事数值 | `systems/EconomySystem.lua` / `MilitarySystem.lua` |
| 让选区系统恢复 | main.lua 取消 `ShowSelectScreen()` 的注释封印 |
