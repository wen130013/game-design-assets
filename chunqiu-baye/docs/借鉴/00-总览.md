# 借鉴总览 · 5 个游戏怎么用

> **这份是入口。** 先看这里，再翻具体游戏。
>
> 覆盖：CK3（十字军之王3）/ EU4（欧陆风云4）/ HOI4（钢铁雄心4）/ 维3（维多利亚3）/ AoH3（历史时代3）
> 建立日期：2026-10-16

---

## 一、一句话：每个游戏学什么

| 游戏 | 学它的 | 别学它的 |
|---|---|---|
| **CK3** | **人物系统**（特质/性格/阴谋/继承）、战斗相克 | AI 决策（藏引擎里） |
| **EU4** | **外交**（CB/停战/关系）、**AI 加法评分** | 引擎常量（拿不到） |
| **HOI4** | **AI 数据表**（`基础100+value`）、生产/宽度 | 工业化体系（不适合春秋） |
| **维3** | **供需定价**、平滑短缺、人口分层 | 53 种商品（太重） |
| **AoH3** | **战斗宽度 + 骰子 + 战术**、占领/同化两阶段 | 回合制（我们是实时） |

## 二、🔴 关键分界线：AI 决策在哪

**这是 5 个游戏最大的区别，决定我们能学到什么。**

| 游戏 | AI 决策位置 | 我们能学吗 |
|---|---|---|
| **CK3** | ❌ C++ 引擎（连 `common/ai/` 都没有） | 只有**节奏参数** |
| **EU4** | ✅ `ai_will_do` / `ai_acceptance` | ✅ **能** |
| **HOI4** | ✅ `ai_strategy` 60+ token | ✅ **能** |
| **维3** | ✅ `00_ai.txt` + `ai_strategies` | ✅ **能** |
| **AoH3** | ✅ 偏好参数全公开 | ✅ **能** |

**结论：想看 AI 怎么设计，学 EU4 / HOI4 / 维3 / AoH3，不要学 CK3。**

### 三家的 AI 模型（可混用）

| 游戏 | 模型 | 核心公式 |
|---|---|---|
| **HOI4** | 统一打分 | `分数 = 基础 100 + value` |
| **EU4** | 加法评分 | 逐项 `add` 累加（如敌视 -1000） |
| **维3** | 系数表 | 利润 × 系数 + 短缺 × 系数 |

**共同点：AI 的"想法"应该是可读可调的数据，不是硬编码。**

## 三、🔴 数据可得性：哪些能信，哪些不能

| 游戏 | 数据源 | 可信度 |
|---|---|---|
| **CK3** | 公开 mod 仓库的 `common/` | ✅ 高（原版同源） |
| **EU4** | 公开 mod 仓库 | 🟡 **中**（**无 `defines`**，引擎常量拿不到） |
| **HOI4** | 公开仓库 `hoi4-files` | ✅ 高（含 defines） |
| **维3** | `Victoria-3-files`（完整脚本层） | ✅ 高 |
| **AoH3** | mod 仓库的 `gameValues/*.json`（69 个） | ✅ 高（**但可能被 mod 改过**） |

**通用原则**（见每份文档的"来源等级标注"）：

```
【文件确证】= 直接从原始文件读到  → 可依赖
【社区反推】= wiki/社区，未确证    → 方向可信，细节存疑
【推测】    = 推理，无证据         → 仅供参考
```

## 六、⚠️ 三条通用红线

### 红线 1：设计意图能学，具体数字不能搬

**实验证明**（详见 CK3 文档 §5.5）：把 CK3 的 `0.03` 系数搬到我们的数值体系：

```
我们的轻步兵伤害 50（CK3 是 10，差 5 倍）
→ 每日伤害只有个位数
→ 打 50 人要 10 天，打 5000 人要 1000 天
```

**同一个系数，配上不同数值，结果差 5 倍。** 数字必须配自己的体系重调。

### 红线 2：版权边界

| 能 | 不能 |
|---|---|
| 读机制、理解原理 | 复制文件进项目 |
| 用自己的代码重写 | 照搬脚本代码 |
| 数值作参考 | 用它的美术/文案 |

### 红线 3：拿不到的，往往也是最没用的

| 拿不到的 | 有用吗 |
|---|---|
| 精确公式系数 | ❌ 脱离原体系就是废纸 |
| AI 决策算法 | ❌ 绑死它的体系 |
| **设计意图** | ✅ **有用，而且我们已经拿到了** |
