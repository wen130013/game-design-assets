|---|---:|---|

| **staple 生活必需** | 15 | grain/fish/fabric/wood 20、groceries/clothes/furniture 30、services 30 |

## 三、🔴 价格机制（维3 的招牌）

> **来源等级：【文件确证】常量 + 【社区反推】插值公式**

### 3.1 价格被硬夹在区间里

`game/common/defines/00_defines.txt` 行 361-363：

```txt
MIN_GOODS_PRICE = 1                    # 基础价下限
PRICE_RANGE = 0.75                     # 最低价 = base×(1-0.75) = 0.25×base
                                       # 最高价 = base×(1+0.75) = 1.75×base
                                       # PRICE_RANGE 锁定在 [0-1]
BUY_SELL_DIFF_AT_MAX_FACTOR = 2        # 买订单达卖订单 2 倍 → 价格触顶
```

**价格区间：`base × 0.25` ~ `base × 1.75`。**

> 💡 **这是"既真实又稳定"的关键设计** —— 价格不会爆炸，也不会归零。

### 3.2 ⚠️ 插值公式拿不到

**`base` 怎么插值到实际价格 —— 在引擎 C++ 里，脚本层没有公式。**

社区通行公式（**【社区反推】，未文件确证**）：

```
price ≈ base × (1 + PRICE_RANGE × (buy - sell) / max(buy, sell))
```

> ⚠️ **诚实说明**：这个公式**方向对**（供需差决定价格），但**精确形式未经确证**。

### 3.3 两层价格

| 概念 | 含义 |
|---|---|
| `market_price`（市场价） | 由**全市场**买卖订单决定 |
| `local_price`（地方价） | 由**本地产销**决定，被市场价按**接入度**调制 |

> 💡 这让"边远地区物价高"自然涌现，机制轻量。

### 3.4 短缺处理 —— 平滑过渡

`00_defines.txt` 行 365-371：

```txt
GOODS_SHORTAGE_PENALTY_THRESHOLD = 0.5        # 供给/需求 < 0.5 开始惩罚
GOODS_SHORTAGE_PENALTY_INCREASE_SPEED = 0.01  # 每天按目标值 1% 上升
GOODS_SHORTAGE_PENALTY_DECREASE_SPEED = 0.01  # 每天按上限 1% 回落
GOODS_SHORTAGE_PENALTY_MIN = 0.05             # 有短缺时惩罚下限
GOODS_SHORTAGE_PENALTY_MAX = 0.5              # 常规上限（产出 -50%）
GOODS_SHORTAGE_PENALTY_MISSING_INPUTS = 0.75  # 某输入品完全断供 → 75%
GOODS_SHORTAGE_PENALTY_MILITARY_BUILDING_SPEED_MULT = 5.0  # 军用建筑升降速 ×5
```

> 💡 **关键**：短缺**不是瞬间惩罚，而是平滑过渡**（每天 1%）。
> 惩罚体现为**建筑产出打折**（最多 -50%，断料 -75%），**不直接销毁需求**。

## 四、市场与接入度

> **来源等级：【文件确证】**

- **市场**：同一市场的州互相贸易；可经**世界市场**互通
- **市场接入度（Market Access）**：州与其市场的连通度
  - 起始 **100%**
  - 当州的**基础设施使用量 > 基础设施供给**时按比例下降
  - 影响：①该州产销生成多少买卖订单；②市场价对地方价的影响权重
- **基础设施**由铁路/港口提供，建筑组有 `infrastructure_usage_per_level`（轻工业 2、重工业 3、农业 1）
- **贸易中心**：每级提供 `state_trade_capacity_add = 10`、`state_weekly_trades_add = 1`

**世界市场枢纽评分**（`00_defines.txt` 行 381-385）：港口每级 10 分、GDP 每 10 万 1 分、市场首都 +100。

## 五、人口（Pops）系统

> **来源等级：【文件确证】**

### 5.1 三阶级 + 15 种职业

| 阶级 | 职业 |
|---|---|
| **upper 上层** | aristocrats、capitalists |
| **middle 中层** | academics、bureaucrats、clergymen、engineers、farmers、officers、shopkeepers |
| **lower 底层** | clerks、laborers、machinists、peasants、slaves、soldiers |

**职业属性**（以 aristocrats 为例）：

```
start_quality_of_life = 20, working_adult_ratio = 0.2, wage_weight = 5,
paid_private_wage = no, literacy_target = 0.60, unemployment = yes
```

peasants 特殊：`subsistence_income = yes`、`consumption_mult = 0.05`。

### 5.2 生活水平（SoL）= 财富等级，共 99 级

```txt
NUM_WEALTH_LEVELS = 99
POP_SIZE_PACKAGE = 10000    # 每"标准人口包"1 万人
```

**财富升降规则**（`00_defines.txt` 行 1165-1169）：

```txt
WEALTH_PROGRESS_WANTED_BUFFER = 1.02      # 收入 ≥ 下级购物包成本×1.02 才升级
WEALTH_PROGRESS_ACCEPTABLE_DEFICIT = 0.98
WEALTH_PROGRESS_INCREASE = 0.2
WEALTH_PROGRESS_DECREASE = 0.1
```

**购物包**（`buy_packages/00_buy_packages.txt`）：**99 级**（wealth_1~99），每级列出该级人口买哪些 `popneed` 及数量，并给 `political_strength`（wealth_1 = 0.03，wealth_99 = 1500）。

**14 种需求**（`pop_needs/00_pop_needs.txt`）：simple_clothing、crude_items、basic_food、heating、household_items、standard_clothing、services、intoxicants、luxury_drinks、free_movement、communication、luxury_food、luxury_items、leisure。

> 💡 **商品替代（goods substitution）**：每个需求含多种可替代商品，带 `weight` / `max_supply_share` / `min_supply_share`。
> **缺粮时自动吃肉** —— 无需复杂求解。

### 5.3 饥饿与激进化

```txt
SOL_STARVING_THRESHOLD = 5
SOL_STRUGGLING_THRESHOLD = 10
FOOD_SECURITY_STARVATION_THRESHOLD = 0.4
RADICALS_MONTHLY_FROM_LOW_SOL = 0.002      # SoL 低于期望 → 每月转激进
RADICALS_MAX_FROM_LOW_SOL = 0.15
SOL_CHANGE_POP_IMPACT_FACTOR = 0.05        # SoL 变化 → 转激进/忠诚比例
```

### 5.4 职业转换靠"资格"

aristocrats 的资格 = 财富与识字率函数：

```
(wealth - 14)/20 + max((wealth - 20)/5, 0)，再乘 (0.5 + literacy/2)
受歧视(acceptance<4) 时 ×0.1；农奴制下 = 0；财富不足每年 -2 衰减
```

切换是**渐进累积**的（`QUALIFICATIONS_UPDATE_FACTOR = 0.0003`）。

## 六、生产方式（Production Methods）

> **来源等级：【文件确证】** —— `production_methods/`（341 个 PM）、`production_method_groups/`（169 个 PMG）

**三层结构**：建筑 → PMG（组）→ PM（组内互斥单选）

**PM 效果三种缩放**：

| 缩放 | 含义 | 例子 |
|---|---|---|
| `workforce_scaled` | 按实际用工人数比例 | `goods_input_grain_add = 40`（满员时耗 40 粮） |
| `level_scaled` | 按建筑等级 | `building_employment_shopkeepers_add = 500`（每级雇 500） |
| `unscaled` | 不缩放 | — |

**产出示例**（`01_industry.txt` 面包厂）：

```
pm_bakery         : 输入 grain 40        → 输出 groceries 45
pm_sweeteners     : 加输入 sugar 15      → 输出提到 65
pm_baking_powder  : 输入 grain 80 + sugar 30 → 输出 120
```

> 💡 **PM 之间是"投入更多 → 产出更多/效率更高"的权衡**，并改变雇佣职业结构。

**解锁条件**：`unlocking_technologies`（科技）、`unlocking_laws`（法律）、`unlocking_production_methods`（前置 PM）、`unlocking_principles`（权力集团原则）。

**建造成本档位**（`script_values/building_values.txt`）：

```

```

### 7.2 投资池

- **机制**：私有建筑利润以**分红**付给各阶层；部分分红**再投资**进投资池，由 pop 用于**私人建造**
- **效率参数**（`00_defines.txt` 行 572-574）：

```txt
REINVESTMENT_EFFICIENCY_MAX = 3.0
REINVESTMENT_BASE_EFFICIENCY_THRESHOLD = 50,000,000   # GDP 低于此值线性提升效率
REINVESTMENT_SUBSISTENCE_FRACTION_REDUCTION = 0.5
```

- **所有权建筑**：`building_manor_house`（地主庄园，aristocrats 持股）、`building_financial_district`（金融区，capitalists 持股）

### 7.3 经济体制法律（8 种）

| 法律 | 关键效果 |
|---|---|
| `law_traditionalism` | 投资池效率 **-50%**、税收容量 -25% |
| `law_laissez_faire` | `private_construction_allocation_mult = 0.75`、`force_privatization = yes` |
| `law_command_economy` | **废除投资池**、国有化成本 -50%、国有化激进 -75% |
| `law_interventionism` / `law_agrarianism` / `law_cooperative_ownership` 等 | — |

**税收法律**（5 档税率）：consumption（0.15~0.35）、land（0.40~1.00）、per_capita、proportional、graduated（需 socialism）。

## 八、🔴 AI 经济决策（明文可读）

> **来源等级：【文件确证】**

**维3 的 AI 经济决策是明文脚本**（这点和 HOI4 一样，和 CK3 相反）。

### 8.1 数值权重：`game/common/defines/00_ai.txt`

```txt
PRODUCTION_BUILDING_BASE_VALUE = 1000          # 无脚本 ai_value 时的基础分
PRODUCTION_BUILDING_GOODS_PROFIT_FACTOR = 5000 # 每 £ 预测利润（除以每级员工数）
PRODUCTION_BUILDING_OUTPUT_HIGH_PRICE_THRESHOLD = 1.25  # 高于 base×1.25 算高价
PRODUCTION_BUILDING_LOW_PRICE_THRESHOLD = 0.75          # 低于 base×0.75 算低价
PRODUCTION_BUILDING_REDUCE_SHORTAGE_MULT = 5     # AI 强烈避免加剧短缺
PRODUCTION_BUILDING_INCREASE_SHORTAGE_MULT = 0.01
CONSTRUCTION_DEBT_PAUSE = 0.4 / RESUME = 0.2     # 债务过高暂停建造
```

### 8.2 策略脚本：`game/common/ai_strategies/00_default_strategy.txt`

- **目标建造产出** `wanted_construction_output`，公式明文：
  ```
  基础 10 + 投资池收入/1000 + 收入/5000(上限200) + 人口/200万(上限100) + 大国加成(列强+75)
  ```
- **补贴清单**：`subsidies = { power_plant/railway/port = must_have }`
- **商品倾向**：`goods_stances`（如 small_arms/artillery = wants_high_supply）
- **国有化意愿**：`nationalization_desire`（命令经济 +100；阈值 `NATIONALIZE_THRESHOLD=1.0` / `PRIVATIZE_THRESHOLD=0.0`）
- **税率目标**：`desired_tax_level = medium`、`max = high`、`min = low`
- **建筑组权重**：`building_group_weights = { bg_agriculture = 1.25 }`

## 九、玩家操作流程（经济怎么管）

```
1. 看市场面板 → 每种商品的买/卖订单、市场价 vs 基础价、短缺建筑数
2. 建生产建筑 → 选州（受基础设施/劳动力/投入品本地可得性影响）
3. 切换生产方式 → 权衡投入/产出/雇佣/自动化
4. 管基础设施 → 修铁路/港口提升接入度 → 地方价贴近市场价 → 短缺缓解
5. 贸易 → 用贸易中心/关税调节进出口
6. 税收与补贴 → 选税制+税率档；对铁路/电厂/港口强制补贴
7. 经济体制 → 传统主义→干预→自由放任，或走命令经济
8. 投资池 → 私人资本自动建造；玩家可设国有/私有
```

## 十、设计意图 —— 为什么玩家会开心

> **来源等级：【推测】** —— 以下是我对设计动机的推理。

| 技巧 | 为什么这样设计 | 玩家感受 |
|---|---|---|
| **价格硬夹区间** | 避免价格爆炸/归零 | 「经济不会崩」 |
| **平滑短缺惩罚** | 渐变而非瞬断，给玩家反应时间 | 「还有机会补救」 |
| **两层价格** | 边远地区物价高，自然涌现 | 「修铁路真有用」 |
| **商品替代** | 缺粮能吃肉，机制轻量 | 「市场自己会调」 |
| **99 级购物包** | 生活水平颗粒度极细 | 「我的人民慢慢富裕了」 |
| **PM 切换** | 投入产出权衡，不是单纯升级 | 「要不要上自动化」 |
| **投资池** | 私人资本自动发展，玩家可干预 | 「经济在自己跑」 |
| **AI 经济明文** | 便于调平衡 | — |

## 十一、我们能借鉴什么

### 11.1 核心可借鉴点

| 借鉴点 | 说明 | 对应我们 | 优先级 |
|---|---|---|---|
| **价格硬夹区间** | 价格 = base × [0.25, 1.75] | `EconomySystem` | 🟡 中 |
| **平滑短缺惩罚** | 每天 1% 渐变，不瞬断 | 经济/补给 | 🟡 中 |
| **商品替代** | `weight` + `max_supply_share` | 粮食系统 | 🟡 中 |
| **🔴 AI 经济评分表** | 明文系数表，可调 | `AIManager.lua` | 🔴 高 |
| **生活水平分级** | 99 级可简化为 10 级 | `CharacterSystem` | ⚪ 低 |

### 11.2 ⚠️ 不能照搬的

| 为什么 |
|---|
| 维3 是**工业革命时代**，53 种商品 + 99 级财富对我们太重 |
| 我们做的是**春秋战国**，经济是"钱粮"而非"工业化" |
| **建议大幅简化**：比如 10~20 种资源、10 级生活水平，保留"供需定价"的**核心思路**即可 |

### 11.3 对 `EconomySystem` 的具体建议

> **来源等级：【推测】**

我们现在的经济是"人口 × 税率"，**没有供需概念**。可考虑：

```
1. 给粮食/金钱加"供需"概念 → 价格浮动
2. 价格夹在 [0.5×, 1.5×] 区间（比维3 保守）
3. 短缺用平滑惩罚（每天 -1% 产出），不要瞬间崩
```

**但这是大改**，应该单独评估，不要顺手做。
