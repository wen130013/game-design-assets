## 一、🔴 维3：法律系统（8 种经济体制）

> **来源等级：【文件确证】** —— `game/common/laws/00_economic_system.txt`

### 1.1 经济体制法律（8 种）

| 法律 | 关键效果 |
|---|---|
| `law_traditionalism` | 投资池效率 **-50%**、税收容量 -25% |
| `law_laissez_faire` | `private_construction_allocation_mult = 0.75`、**强制私有化** |
| `law_command_economy` | **废除投资池**、国有化成本 -50% |
| `law_interventionism` | — |
| `law_agrarianism` | — |
| `law_industry_banned` | — |
| `law_extraction_economy` | — |
| `law_cooperative_ownership` | — |

### 1.2 税收法律（5 档）

```
consumption（消费税）:  0.15 ~ 0.35
land（土地税）:        0.40 ~ 1.00
per_capita（人头税）
proportional（比例税，含 income/dividends）
graduated（累进税，需 socialism）
```

> 💡 **法律是"体制级"的选择** —— 不是 +5% 这种小修正，
> 而是**决定整个经济怎么运作**（有没有投资池、能不能私有化）。

### 1.3 🔴 关键设计：法律有"解锁条件"

维3 的法律不是随便选，需要**科技/权力集团**解锁：

```txt
law_laissez_faire  需要 international_trade
law_command_economy 需要 central_planning
law_cooperative_ownership 需要 ...
```

> 💡 **这让"改法律"成为一个有门槛的决策**，而不是随时切换。

## 二、HOI4：国策树 + 连续国策

> **来源等级：【文件确证】** —— `common/national_focus/`、`common/continuous_focus/`

### 2.1 国策树（详见 `03-钢铁雄心4.md` §五）

```txt
focus = {
    id = GER_four_year_plan
    prerequisite = { focus = GER_xxx }          # 前置
    mutually_exclusive = { focus = GER_yyy }    # 互斥
    available = { <trigger> }                   # 显示但灰
    bypass = { <trigger> }                      # 条件满足直接跳过并给奖励
    cost = 10                                   # 1点 = 7天 → 10点 = 70天
    ai_will_do = { factor = 12 }                # AI 权重
    completion_reward = { ... }
}
```

**关键参数**：

```txt
FOCUS_PROGRESS_PEACE/WAR = 1
MAX_SAVED_FOCUS_PROGRESS = 10        # 未选焦点时最多存 10 天进度
```

### 2.2 🔴 连续国策（1.11+，值得注意）

> **来源等级：【文件确证】** —— `common/continuous_focus/generic.txt`

```txt
daily_cost = 1                          # 每日扣政治点
MIN_FOCUSES_FOR_CONTINUOUS = 10         # 需先完成 10 个国策才解锁
supports_ai_strategy = ...              # 声明 AI 用途
```

> 💡 **"连续国策"是常驻加成** —— 不是一次性解锁，而是**每天花点换持续效果**。
> 这让后期也有可花政治点的地方。

### 2.3 bypass（条件满足自动跳过）

```txt
bypass = { <trigger> }    # 条件满足 → 直接跳过并给奖励
```

> 💡 **避免玩家点"已经没意义"的国策** —— 很实用的设计。

## 三、EU4：政体 + 理念

> **来源等级：【文件确证】** —— `common/governments/`、`common/ideas/`

### 3.1 政体（Governments）

`common/governments/` 目录下有政体定义，含：
- 政体修正
- 可用的改革
- AI 偏好

### 3.2 理念组（Ideas）

**结构**：一组 7 个槽位，每点一个给修正，点满给"完成奖励"。

**特点**：
- 理念是**国家选的**（不像 CK3 是文化自动推）
- 有 `ai_will_do` 权重

### 3.3 政府改革

`common/government_reforms/` —— 政体内部的改革，逐步解锁。

## 四、CK3：法律

> **来源等级：【文件确证】** —— `common/laws/`

CK3 的法律分几大类：
- 继承法（决定死后怎么分家）
- 性别法
- 王权法
- 封臣义务

**特点**：法律有**等级**（如王权 0~4），逐步提升，提升要付出代价（封臣不满）。

> 💡 **"提升法律 → 封臣不满"是核心权衡** —— 集权 vs 稳定。

## 六、我们能借鉴什么

### 6.1 值得学的（按优先级）

| 借鉴点 | 来源 | 为什么好 |
|---|---|---|
| **🔴 政策要有"代价"** | CK3（封臣不满） | 不是白拿加成，有取舍 |
| **政策有解锁条件** | 维3（科技/集团） | 有门槛，不是随时切 |
| **树状：前置 + 互斥** | HOI4 | 让选择有意义 |
| **bypass（自动跳过）** | HOI4 | 避免点无意义政策 |
| **"连续型"常驻政策** | HOI4 | 后期也有可花资源的地方 |

### 6.2 🔴 最契合我们的：政策的"代价"

**你 `TODO.md` 已记录**：

> "2026-09-16 删：TAX_RATES / DEFAULT_TAX（税率四档废弃）
> **用户：'国家面板里的税率和政策那里好像重复了' → 经济杠杆交给政策卡**"

**这说明你已经把政策作为核心经济杠杆了。** 那么"代价"就很重要：

| CK3 的做法 | 我们可以 |
|---|---|
| 提升王权 → 封臣不满 | 加税 → 民心下降？ |
| 中央集权 → 地方反抗 | 变法 → 旧贵族反对？ |

**你 `Policies.lua` 里有"变法"** —— 这天然就该有代价。

### 6.3 ⚠️ 不能照搬的

| 为什么 |
|---|
| 维3 的法律绑死它的**工业经济体制** |
| HOI4 的国策绑死**二战国家** |
| 我们的政策应该是**春秋战国的**（变法/礼制/军功爵） |
