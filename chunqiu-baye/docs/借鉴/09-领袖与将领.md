### 1.2 🔴 三个关键设计

**① 数值很小，但很具体**

```
forest_fighter  → forest_advantage = 5
desert_warrior  → desert_advantage = 5
```

**"优势 +5"**（CK3 里优势影响伤害）——
**不是"+50% 伤害"这种粗暴数值。**

**② 地形特质是"一组地形"**

```txt
desert_warrior = {
    drylands_advantage = 5
    desert_advantage = 5
    desert_mountains_advantage = 5
    oasis_advantage = 5
    desert_cancel_negative_supply = yes    # 沙漠无补给惩罚
}
```

**覆盖 4 种沙漠类地形** —— 不是单一地形。

**③ `trait_exclusive_if_realm_contains`（领地条件）**

```txt
trait_exclusive_if_realm_contains = { ... }
```

**官方说明**（`_traits.info`）：

> "These traits are only assigned/considered if the commander's culture
> contains a province that has one of the terrain types specified"

**翻译**：**你的领地里没有沙漠，就不会出现"沙漠战士"特质。**

> 💡 **这很聪明** —— 特质**跟着地理走**，不会出现"中原将领擅长沙漠战"的怪事。

### 1.3 🔴 你已借鉴的规则

> **你的 `TODO.md` 已记录**：
> "**只有掌兵（大将军/兵部尚书）才生效**（`Traits.MILITARY_POSTS`），
> 照 CK3 的 commander traits：**没带兵的人挂着不算**"

**这是 CK3 的核心设计** —— `commander = yes` 标记的特质**只在带兵时生效**。

## 二、🔴 HOI4：将领系统（131 个特质）

> **来源等级：【官方文档】** —— `common/unit_leader/00_traits.txt`

### 2.1 六种技能

```txt
attack_skill            # 攻击
defense_skill           # 防御
logistics_skill         # 后勤
planning_skill          # 计划
maneuvering_skill       # 机动
coordination_skill      # 协同
```

**每项技能有等级，升级花成本**（【文件确证】）：

```txt
leader_attack_skills = {
    1 = { cost = 100  type = navy  modifier = { naval_damage_factor = 0.05 } }
    2 = { ... }
}
```

> 💡 **技能是"加点"而非"固定值"** —— 将领可以培养。

### 2.2 🔴 131 个特质按两个维度分类

**维度 1：`trait_type`（特质类型）**

| 类型 | 数量 |
|---|---:|
| `assignable_trait`（可指派） | **46** |
| `personality_trait`（性格） | 36 |
| `basic_terrain_trait`（基础地形） | 12 |
| `status_trait`（状态） | 9 |
| `basic_trait`（基础） | 8 |
| `assignable_terrain_trait` | 2 |
| `exile`（流亡） | 1 |

**维度 2：`type`（适用兵种）**

| 兵种 | 数量 |
|---|---:|
| `navy`（海军） | **47** |
| `corps_commander`（军长） | 37 |
| `land`（陆军） | 14 |
| `field_marshal`（元帅） | 10 |
| `operative`（特工） | 12 |
| `all`（通用） | 9 |

> 💡 **两个维度交叉** —— 特质既分"类型"又分"适用兵种"。
> **我们的将领不分兵种，这个维度可简化。**

### 2.3 🔴 真实特质结构（【文件确证】）

```txt
old_guard = {
    type = land
    trait_type = personality_trait
    modifier = {
        max_dig_in = 1              # 堑壕上限 +1
    }
    non_shared_modifier = {
        experience_gain_factor = -0.25   # ⚠️ 经验获取 -25%（代价！）
    }
    new_commander_weight = { factor = 1 }
}

brilliant_strategist = {
    type = land
    trait_type = personality_trait
    attack_skill = 1                # 攻击技能 +1
    planning_skill = 1              # 计划技能 +1
    attack_skill_factor = 1
    planning_skill_factor = 1
    new_commander_weight = { factor = 1 }
}

inflexible_strategist = {
    type = land
    trait_type = personality_trait
    defense_skill = 1
    logistics_skill = 1
    defense_skill_factor = 1
    logistics_skill_factor = 1
}
```

### 2.4 🔴 关键设计：特质有"代价"

**注意 `old_guard`**：

```
好处：max_dig_in = 1        （堑壕 +1）
代价：experience_gain_factor = -0.25  （经验 -25%）
```

> 💡 **"老卫兵"经验涨得慢** —— 有得有失。
> **比"纯加成特质"有意思。**

### 2.5 成长机制

**官方字段**（【官方文档】）：

```txt
gain_xp = trigger                   # 什么条件下获得经验
gain_xp_leader = trigger
gain_xp_on_spotting = 0
trait_xp_factor = {}                # 经验倍率
mutually_exclusive = other_trait    # 互斥
parent = other_trait                # 前置
num_parents_needed = -1             # -1 = 需要全部前置
cost = 1000                         # 花费
new_commander_weight = {}           # 新将领获得此特质的权重
```

> 💡 **将领特质是"打出来"的** —— 通过实战条件成长。

## 五、我们能借鉴什么

### 5.1 值得学的（按优先级）

| 借鉴点 | 来源 | 为什么好 |
|---|---|---|
| **🔴 特质要有代价** | HOI4 `old_guard` | 不是纯加成，有取舍 |
| **🔴 地形特质跟地理走** | CK3 `trait_exclusive_if_realm_contains` | 避免"中原将领擅长沙漠战"的怪事 |
| **🔴 将领特质实战成长** | HOI4 `gain_xp` | 打出来的将领有感情 |
| **地形专精（一组地形）** | CK3（4 种沙漠） | 比单一地形更合理 |
| **技能加点** | HOI4（6 项） | 将领可培养 |
| **性格影响 AI** | EU4 | 君主性格 → 国家行为 |

### 5.2 🔴 最该注意的：特质要有代价

**HOI4 的 `old_guard`**（【文件确证】）：

```
好处：堑壕上限 +1
代价：经验获取 -25%
```

**CK3 的 `cautious_leader`**：

```
min_combat_roll = 4        # 最低掷骰提高（保底）
max_combat_roll = -2       # 最高掷骰降低（上限低）
```

> 💡 **"谨慎"意味着"不会大胜，但也不会大败"** ——
> **这是一个"风险偏好"的选择，不是纯加强。**

### 5.3 🔴 最契合我们的：地形特质 + 地理条件

**CK3 的做法**（【文件确证】）：

```txt
trait_exclusive_if_realm_contains = { ... }
```

**官方说明**：

> "These traits are only assigned/considered if the commander's culture
> contains a province that has one of the terrain types specified"

**翻译**：**你的领地里没有沙漠，就不会出现"沙漠战士"。**

**为什么好**：

| 好处 | 说明 |
|---|---|
| **特质跟地理走** | 不会出现"中原将领擅长沙漠战" |
| **自然形成地域特色** | 北方的将领擅长寒地，南方的擅长水战 |
| **你已有 `TerrainReal.lua`** | 数据现成 |

### 5.4 ⚠️ 不能照搬的

| 为什么 |
|---|
| HOI4 是**二战**，131 个特质里 47 个是海军、12 个是特工 |
| CK3 是**中世纪欧洲**，地形绑死它的体系 |
| 我们的将领应该是**春秋战国的**（如"善御""善射"） |
