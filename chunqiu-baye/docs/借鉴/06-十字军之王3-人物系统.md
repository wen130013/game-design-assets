## 一、核心洞察：CK3 人物系统为什么强

**一句话：它把"人"变成了玩法的载体，而不是数值的容器。**

| 传统策略游戏 | CK3 |
|---|---|
| 将领 = 攻击力 +10 | 将领 = 性格 + 野心 + 对你有意见 |
| 大臣 = 产出 +5% | 大臣 = 可能背叛你 |
| 继承 = 换个人继续 | 继承 = **玩法本身**（内战/分裂） |

**三个支撑机制**：

1. **性格对立** —— 人有立场，会互相看不顺眼
2. **阴谋** —— 人有野心，会暗中动手
3. **继承** —— 人有后代，死亡不是结束

## 二、特质系统（278 个）

> **来源等级：【文件确证】** —— `common/traits/00_traits.txt`

### 2.1 规模与分类

| 类别 | 数量 | 说明 |
|---|---:|---|
| **personality 性格** | **67** | 核心，有对立关系 |
| fame 名望 | 62 | 事迹带来的 |
| physical 生理 | 38 | 外貌/身体 |
| genetic 遗传 | 34 | 可遗传 |
| lifestyle 生活方式 | 31 | 三条线获得 |
| education 教育 | 20 | 幼年教育决定 |
| commander 军事 | 17 | 带兵才生效 |
| **总计** | **278** | |

### 2.2 🔴 性格对立（核心机制）

**每个性格特质都有"同类好感"和"对立好感"**：

```txt
brave = {
    personality = yes
    same_opinion = 1          # 同样勇敢的人 → 互相 +1 好感
    opposite_opinion = -1     # 对立性格 → -1 好感

    opposites = {             # 明确列出对立特质
        vulnerable
        anxious
        paranoid
        sentimental
        craven
    }
}
```

**真实的对立组**（`opposites` 字段，【文件确证】）：

| 特质 | 对立于 |
|---|---|
| `brave`（勇敢） | vulnerable / anxious / paranoid / sentimental / **craven（怯懦）** |
| `diligent`（勤勉） | organized / careful / thorough ... |
| `just`（公正） | arbitrary ... |

> 💡 **机制意图【推测】**：
> **让 NPC 之间自动产生"合得来/合不来"** ——
> 不需要专门写"谁讨厌谁"，性格本身就决定了。
> **这是 N² 关系网的轻量解法**（CK3 有几万角色，不能两两配对写关系）。

**⚠️ 注意一个实现细节**（【文件确证】）：

```txt
potential = {
    NOR = {                       # 不能同时拥有
        has_trait = tough
        has_trait = craven
        ...
    }
}
```

**对立特质互斥** —— 一个人不可能既勇敢又怯懦。

### 2.3 🔴 遗传机制（官方文档）

> **来源等级：【官方文档】** —— `_traits.info`

```txt
genetic = yes/not        # 是否遗传
inherit_chance = X       # 传给子女的概率
birth = X                # 每 100 个新生儿中有几个天生带此特质
random_creation = X      # 每 100 个生成角色中有几个带此特质

parent_inheritance_sex = male/female/all   # 能从哪方父母继承
child_inheritance_sex = male/female/all    # 能传给哪种性别子女
enables_inbred = yes/no                    # 是否启用"近亲繁殖"判定
```

**遗传规则**（原文）：

> "An active trait is inherited with **100% chance**, an inactive trait with a **50% chance**.
> If the trait is successfully inherited from both parents, it becomes active."

```
活跃特质  → 100% 遗传
非活跃特质 → 50% 遗传
双亲都传 → 变活跃
```

> 💡 **"隐性/显性"设计** —— 让血统有"隔代遗传"的效果，增加王朝叙事的戏剧性。

### 2.4 触发式好感

> **来源等级：【官方文档】**

```txt
triggered_opinion = {
    opinion_modifier = opinion_modifier_key
    same_faith = yes              # 只对同信仰生效
    same_dynasty = yes            # 只对同王朝生效
    male_only = yes / female_only = yes
    check_missing = yes           # 检查参数是"未设置"
    ignore_opinion_value_if_same_trait = yes
}
```

> 💡 **同一条特质，对不同人产生不同好感** —— 比"固定 +10"细腻得多。

### 2.5 其他关键字段（官方文档）

| 字段 | 作用 |
|---|---|
| `health = X.X` | 改实际健康值 |
| `fertility = X.X` | 生育率乘数 |
| `immortal = yes` | 停止衰老 + 免疫自然死亡 |
| `good = yes/no` | 标记为"好特质" |
| `physical = yes` | 标记为生理特质 |
| `blocks_from_claim_inheritance` | 阻止继承宣称 |
| `forced_portrait_age_index` | 强制立绘年龄 |
| `portrait_extremity_shift` | 立绘基因偏移（如"变丑"） |

## 三、🔴 阴谋系统（5 种）

> **来源等级：【官方文档】** —— `common/schemes/_schemes.info`

### 3.1 五种阴谋（【文件确证】）

| 阴谋 | 文件 | 类型 |
|---|---|---|
| **谋杀** `murder` | `murder_scheme.txt` | hostile |
| **绑架** `abduct` | `abduct_scheme.txt` | hostile |
| **夺位** `claim_throne` | `claim_throne_scheme.txt` | hostile |
| **求爱** `seduce` | `seduce_scheme.txt` | personal |
| **宫廷** `court` | `court_scheme.txt` | personal |

### 3.2 🔴 核心公式（官方文档原文）

> **"Progress chance each month is scheme power minus scheme resistance."**
> （每月进度概率 = 阴谋力量 − 抵抗）

```txt
power_per_skill_point = 0.1                    # 主谋每点技能 → 力量
power_per_agent_skill_point = 1                # 每个参与者每点技能 → 力量
spymaster_power_per_skill_point = 1            # 间谍首脑加成
spymaster_resistance_per_skill_point = 1       # 间谍首脑抵抗
tier_resistance = 1                            # 目标等级抵抗
```

**举例**（官方文档给的）：

```
主谋 50 力量，目标 25 抵抗
→ 每月进度概率 = 25%
```

### 3.3 三个数值（官方文档）

| 数值 | 范围 | 含义 |
|---|---|---|
| **Success Chance** | 0-100 | 成功率 |
| **Secrecy** | 0-100 | 保密度 |
| **Scheme Progress** | **0-10** | 进度（攒满触发） |

### 3.4 保密与暴露（官方文档）

> **"base_secrecy + success_chance + scheme_modifiers, clamped to 0-100"**

```txt
is_secret = yes        # 是否使用保密机制（否则恒 100% 保密）
base_secrecy = -20     # 基础保密（负值 = 更容易暴露）
```

**每月检查一次是否暴露** —— 保密度越低，越容易被发现。

### 3.5 参与者机制（官方文档）

```txt
agent_join_threshold = 5    # AI 想加入的意愿达到多少才真加入
agent_leave_threshold = 1   # 低于此值自动退出
uses_agents = no            # 设为 no 则不能拉人
agent_join_chance = { base = 0  modifier = { add = 10 } }
agent_success_chance = {}   # 每个参与者给成功率加多少
```

> 💡 **AI 拉人也是"打分制"** —— 意愿 ≥ 5 才加入，< 1 就退出。

### 3.6 谋杀的具体条件（【文件确证】）

```txt
murder = {
    skill = intrigue          # 基于谋略技能
    hostile = yes
    allow = { is_adult = yes  is_imprisoned = no }
    valid = {
        # 不能谋杀自己的子女（除非有 can_murder_own_children 特质）
        # 不能谋杀已在监狱里的人
        # 不能谋杀已经发现你图谋的人
        # 目标必须在你的外交范围内
    }
}
```

## 五、玩家操作流程

### 5.1 培养人物

```
1. 子女幼年 → 选教育焦点（5 种：军事/外交/管理/谋略/学识）
2. 成年 → 获得教育特质（3 档）
3. 成年后 → 选生活方式（5 条线），攒经验解锁 perk
4. 特质上限：每人 3 个性格特质（MAX_PER_CHAR = 3）
```

### 5.2 搞阴谋

```
1. 选目标 → 选阴谋类型（谋杀/绑架/夺位/求爱/宫廷）
2. 拉参与者 → AI 按意愿打分决定加不加入
3. 每月结算：进度概率 = 力量 − 抵抗
4. 进度攒满 10 → 触发
5. 同时每月检查是否暴露（保密度越低越容易）
```

### 5.3 经营王朝

```
1. 结婚 → 生育 → 子女继承特质（遗传机制）
2. 安排继承 → 分割继承法 → 死后诸子分家
3. 防止近亲繁殖 → enables_inbred 判定
```

## 六、设计意图 —— 为什么玩家会开心

> **来源等级：【推测】**

| 技巧 | 为什么这样设计 | 玩家感受 |
|---|---|---|
| **性格对立** | NPC 自动产生爱憎，不用手工配对 | 「这俩人天生不对付」 |
| **对立特质互斥** | 人不能既勇敢又怯懦 | 「我儿子性格随他妈」 |
| **隐性遗传** | 隔代遗传，王朝有戏剧性 | 「我爷爷的暴脾气又回来了」 |
| **触发式好感** | 同一特质对不同人效果不同 | 「他因为同信仰对我好」 |
| **阴谋 = 力量 − 抵抗** | 一个公式搞定所有阴谋 | 「我谋略高，成功率大」 |
| **保密度** | 阴谋可能暴露，有风险 | 「被发现了！」 |
| **AI 拉人打分** | 参与者有自己的判断 | 「他不愿意跟我干」 |
| **继承是玩法** | 死亡不是结束 | 「我一死，儿子们要打起来」 |

### 7.2 建议（按优先级）

#### 🔴 高：加"触发式好感"

**现状**：我们可能只有"固定好感"。
**CK3 做法**：好感可以**带条件**。

```lua
-- 照 CK3 的 triggered_opinion
triggered_opinion = {
    opinion_modifier = "same_faith_bonus",
    same_faith = true,           -- 只对同信仰
    same_dynasty = false,
}
```

**价值**：让"关系"更有层次，不用手工写死。

#### 🟡 中：加"隐性遗传"

**CK3 规则**（官方文档确证）：

```
活跃特质 → 100% 遗传
非活跃特质 → 50% 遗传
双亲都传 → 变活跃
```

**价值**：让王朝有"隔代遗传"的戏剧性。

#### 🟡 中：加阴谋系统（大工程）

**CK3 核心公式**（官方文档确证）：

```
每月进度概率 = 阴谋力量 − 抵抗
进度 0~10 攒满触发
保密度决定是否暴露
```

**最小可用版本**（建议）：

| 阴谋 | 值不值得做 |
|---|---|
| **谋杀** | ✅ 最经典 |
| **夺位** | ✅ 契合春秋（弑君） |
| 绑架 | 🟡 |
| 求爱 | 🟡 |
| 宫廷 | ⚪ |

**⚠️ 但这是大工程**，涉及：新的数据模型、每月结算、UI 面板、AI 参与判断。
**建议单独评估，不要顺手做。**

#### ⚪ 低：生活方式

CK3 有 5 条线（军事/外交/管理/谋略/学识），攒经验解锁 perk。
**我们已有教育特质 4 档，暂不缺这块。**
