## 一、🔴 AoH3 省份经济（最贴近我们）

> **来源等级：【文件确证】** —— `GV_Economy.json` 等

### 1.1 投资机制（边际成本递增）

```json
{
    "INVEST_IN_PROVINCE_DAYS": 100,        // 投资要 100 天
    "INVEST_COST": 15,                     // 基础成本 15
    "INVEST_COST_PER_ECONOMY": 0.6,        // ⚠️ 每点经济 +0.6 成本
    "INVEST_ECONOMY_GROWTH": 1.25,         // 每次投资涨 1.25 经济
    "INCOME_ECONOMY_PER_ECONOMY": 0.03,    // 每点经济给 0.03 收入
}
```

> 💡 **边际成本递增** —— 越发达的地方，继续投资越贵。
> **防止玩家把资源全堆一个省。**

### 1.2 🔴 三档税收（极清晰的设计）

```json
{
    "TAXATION_LEVEL_EFFICIENCY":     [-0.2,  0,    0.15],
    "TAXATION_LEVEL_INCOME_ECONOMY": [-0.1,  0,    0.075],
    "TAXATION_LEVEL_RESEARCH":       [0.05,  0,   -0.05],
    "TAXATION_LEVEL_LEGACY":         [0.25,  0,   -0.5],
    "TAXATION_LEVEL_UNREST_PER_MONTH":[-0.5, -0.1,  0.75]
}
```

**解读成表**（数组三档：低/中/高）：

| 档位 | 税收效率 | 收入 | 研发 | 遗产 | **不满/月** |
|---|---:|---:|---:|---:|---:|
| **低税** | -20% | -10% | **+5%** | **+25%** | **-0.5** |
| **中税** | 0 | 0 | 0 | 0 | -0.1 |
| **高税** | **+15%** | **+7.5%** | **-5%** | **-50%** | **+0.75** |

> 💡 **这是"一表看尽权衡"的典范**：
> - 低税 → 不满下降、研发加成，但收入少
> - 高税 → 收入多，但**不满涨、研发降、遗产掉**

### 1.3 🔴 三档研发投入

```json
{
    "RESEARCH_LEVEL_RESEARCH": [-0.75,  0,   0.25],
    "RESEARCH_LEVEL_COST":     [-0.75,  0,   0.5]
}
```

| 档位 | 研发 | 成本 |
|---|---:|---:|
| 低 | **-75%** | **-75%** |
| 中 | 0 | 0 |
| 高 | **+25%** | **+50%** |

> 💡 **"高投入 = 研发快但贵"** —— 清晰的权衡。

### 1.4 🔴 三档军费

```json
{
    "MILITARY_LEVEL_ARMY_MAINTENANCE": [-0.25, 0,    0.25],
    "MILITARY_LEVEL_MANPOWER":         [-0.5,  0,    0.25],
    "MILITARY_LEVEL_MORALE":           [0.8,   1.0,  1.1],
    "MILITARY_LEVEL_REINFORCE_SPEED":  [0.25,  1.0,  1.25]
}
```

| 档位 | 维护费 | 人力 | **士气** | 补员 |
|---|---:|---:|---:|---:|
| 低 | -25% | -50% | **0.8** | 0.25 |
| 中 | 0 | 0 | **1.0** | 1.0 |
| 高 | **+25%** | **+25%** | **1.1** | **1.25** |

> 💡 **"低军费"不是没用** —— 省钱，但士气和补员差。
> **让"和平时期省钱"成为策略。**

### 1.5 🔴 借贷（有上限）

```json
{
    "MAX_NUMBER_OF_LOANS": 2,           // ⚠️ 最多 2 笔贷款
    "LOAN_VALUE_MIN": 30.0,
    "LOAN_VALUE_BY_ECONOMY": 0.4,       // 按经济规模
    "LOAN_DAYS": 365,
    "LOAN_YEARS": 10,
    "LOAN_DEFAULT_INTEREST": 3.75,      // 利息 3.75
    "LOAN_INFLATION": 0.0015            // ⚠️ 借贷会推高通胀
}
```

> 💡 **贷款上限 2 笔 + 推高通胀** ——
> **借钱有代价，不能无限借。**

### 1.6 国库上限

```json
{
    "MAX_AMOUNT_OF_GOLD_MIN": 3000,
    "MAX_AMOUNT_OF_GOLD_PER_INCOME": 10    // 上限 = 收入 × 10
}
```

> 💡 **国库有上限** —— 防止无限攒钱。

### 1.7 省份分级

```json
{
    "GROWTH_RATE_VILLAGE": 14,
    "GROWTH_RATE_TOWN": 30,
    "GROWTH_RATE_CITY": 50,
    "GROWTH_RATE_MAJOR_CITY": 80
}
```

**村庄 → 城镇 → 城市 → 大城市**，增长率递增。

## 二、🔴 CK3 经济（真实常量）

> **来源等级：【文件确证】** —— `00_defines.txt`

### 2.1 🔴 债务机制（分档惩罚）

```txt
DEBT_MODIFIER_THRESHOLDS = { 0  12  24  36  48  60  120  300  600  1200 }
MONTHS_OF_INCOME_AT_START = 18      # 开局带 18 个月收入的现金
```

**解读**：债务惩罚按"欠了多少个月收入"**分 10 档**：

```
欠 0~12 个月  → 第 1 档惩罚
欠 12~24 个月 → 第 2 档（更重）
...
欠 1200+ 个月 → 第 10 档（最重）
```

> 💡 **债务是"渐进制裁"** —— 欠得越多，惩罚越重。
> **不是"欠钱就立刻崩"。**

### 2.2 🔴 发展度（分档）

```txt
LEVELS_DEVELOPMENT = { 100 200 300 400 500 600 700 800 900 }
DEFAULT_COUNTY_DEVELOPMENT = 0
DEVELOPMENT_SPREAD_NEIGHBOUR_FACTOR = 0.1        # 向邻居扩散 10%
DEVELOPMENT_SPREAD_USES_HIGHEST_NEIGHBOUR = yes  # 只按最高的邻居算
```

**解读**：

```
发展度每 100 一档，共 9 档（100~900）
发展度会向邻居"扩散"（每次 10%）
且只看最高的邻居（避免重复计算）
```

> 💡 **"发展度扩散"是个巧妙设计** ——
> 一个发达的城市会带动周边。
> **这让"区域发展"自然涌现。**

### 2.3 领地收入惩罚

```txt
INCOME_PENALTY_PER_COUNTY_ABOVE_LIMIT = 0.05    # 每超 1 郡，收入 -5%
VALUE_INCOME_MULT = 50                          # 封臣收入系数
GOLD_COST_PER_SOLDIER = 0.003                   # 每兵维护费
RAID_ARMY_COST_MULT = 0.5                       # 掠夺军维护费减半
```

### 2.4 头衔创建成本（分级）

```txt
CREATE_TITLE_GOLD_COST = { 0 0 0 250 500 1000 }   # 按层级
USURP_TITLE_GOLD_COST  = { 0 0 0 250 500 1000 }
```

> 💡 **前三级免费，后三级递增** —— 建公国 250、王国 500、帝国 1000。

### 2.5 攻城掠夺

```txt
SIEGE_LOOOT_MULTIPLIER = 40    # 占领收益 = 领地收入 × 40
```

## 三、EU4 经济（地产系统）

> **来源等级：【文件确证】** —— `common/estates/`、`common/estate_crown_land/`

### 3.1 🔴 地产（Estates）—— EU4 经济的核心

**三种主要地产**（从 mod 文件看）：

```
nobles（贵族）
burghers（市民）
clergy（教士）
+ 文化少数群体、贸易公司等
```

**地产有关键属性**（【文件确证】）：

| 属性 | 含义 |
|---|---|
| **影响力（influence）** | 地产的政治力量 |
| **忠诚度（loyalty）** | 地产对君主的态度 |
| **王室领地份额** | 君主直接控制的土地比例 |

### 3.2 🔴 王室领地（Crown Land）—— 核心机制

**这是 EU4 最精妙的经济设计之一**：

```
王室领地份额 = 君主直接控制的土地占比
  ├─ 份额高 → 收入多、权威强
  └─ 份额低 → 地产强势、可能叛乱
```

**交互例子**（【文件确证】）：

```txt
interaction = {
    key = sale_of_titles            # 「卖官鬻爵」
    cooldown_months = 60            # 60 个月冷却
    trigger = { crown_land_share = 10 }   # 王室领地 ≥10% 才能用
    effect = {
        # 按时代给不同的"领地年收入"
        age_of_discovery:   add_years_of_estate_land_income = 2.5
        age_of_reformation: 2.0
        age_of_absolutism:  1.5
        age_of_revolutions: 1.0
    }
}
```

> 💡 **"卖官鬻爵"** —— 拿现金，但**王室领地份额下降**。
> **短期解困 vs 长期削弱王权。**

### 3.3 建筑（含奇观）

**真实例子**（【文件确证】）：

```txt
el_escorial = {                     # 埃斯科里亚尔修道院
    cost = 10000
    time = 240
    onmap = no
    one_per_country = yes           # 全国唯一
    build_trigger = { is_capital = yes  FROM = { tag = SPA } }
    modifier = {
        prestige = 0.5
        legitimacy = 1
        papal_influence = 1
        state_maintenance_modifier = -0.1
        global_autonomy = -0.05
        yearly_absolutism = 0.25
    }
    ai_will_do = { factor = 0 }
}

blast_furnace = {                   # 高炉
    cost = 2000
    time = 60
    onmap = no
}
```

> 💡 **建筑有"全国唯一"限制**（`one_per_country`）——
> 奇观只能建一个。

## 四、维3 经济（对比参考）

> **来源等级：【文件确证】** —— 详见 `04-维多利亚3.md`

### 4.1 建筑组（含官方字段注释）

```txt
bg_manufacturing = {
    category = urban
    always_possible = yes
    economy_of_scale = yes          # ⚠️ 规模经济
    cash_reserves_max = 25000
    should_auto_expand = { default_auto_expand_rule = yes }
}
```

> 💡 **`economy_of_scale`（规模经济）** ——
> 建筑等级越高，产出效率越高。
> **这和 AoH3 的"边际成本递增"是相反的激励。**

### 4.2 关键对比

| 机制 | 维3 | AoH3 |
|---|---|---|
| 规模效应 | **规模经济**（越大越省） | **边际成本递增**（越大越贵） |
| 效果 | 鼓励集中 | 抑制集中 |

> 💡 **两种设计各有道理**：
> - 维3 鼓励"建大工厂"（工业化逻辑）
> - AoH3 抑制"堆一个省"（平衡逻辑）
> **我们做春秋战国，可能 AoH3 的思路更合适。**

## 七、我们能借鉴什么

### 7.1 值得学的（按优先级）

| 借鉴点 | 来源 | 为什么好 |
|---|---|---|
| **🔴 三档税制（带副作用）** | AoH3 | 一表看尽权衡，**正是你需要的** |
| **🔴 债务分档惩罚** | CK3（10 档） | 欠得多罚得重，但渐进 |
| **🔴 发展度扩散** | CK3（向邻居 10%） | 区域发展自然涌现 |
| **投资边际成本递增** | AoH3 `0.6/点` | 防止堆一个省 |
| **借贷有上限 + 推通胀** | AoH3（限 2 笔） | 借钱有代价 |
| **国库上限** | AoH3（收入×10） | 防止无限攒钱 |
| **王室领地** | EU4 | 君主 vs 贵族的博弈 |

### 7.2 🔴 最该注意的：三档税制

**你 `TODO.md` 记录**：

> "2026-09-16 删：TAX_RATES / DEFAULT_TAX（税率四档废弃）
> 用户：'国家面板里的税率和政策那里好像重复了' → 经济杠杆交给政策卡"

**你删掉了税率档位。** 但 AoH3 的三档税制**设计得非常干净**：

| 档位 | 收入 | 研发 | 遗产 | **不满/月** |
|---|---:|---:|---:|---:|
| 低税 | -10% | **+5%** | **+25%** | **-0.5** |
| 中税 | 0 | 0 | 0 | -0.1 |
| 高税 | **+7.5%** | **-5%** | **-50%** | **+0.75** |

> 💡 **注意"不满"这一列** ——
> **低税让民心安定，高税让民心浮动。**
> **这不只是"经济杠杆"，是"政治代价"。**
>
> **这可能正是你删掉四档税率后缺的东西** ——
> 政策卡可以管"长期方向"，但**"当前税率"是一个独立的、每天在影响民心的旋钮**。

### 7.3 另一个值得学的：债务分档

**CK3 的 10 档**（【文件确证】）：

```txt
DEBT_MODIFIER_THRESHOLDS = { 0 12 24 36 48 60 120 300 600 1200 }
```

**欠 0~12 个月收入 → 第 1 档；欠 1200+ 个月 → 第 10 档。**

**比"欠钱就掉士气"精细得多。**

### 7.4 ⚠️ 不能照搬的

| 为什么 |
|---|
| AoH3 的数值配它的回合制节奏 |
| 维3 的 53 种商品 + 99 级财富太重 |
| EU4 的地产绑死欧洲封建三级议会 |
| 我们的经济是"钱粮"两元 |
