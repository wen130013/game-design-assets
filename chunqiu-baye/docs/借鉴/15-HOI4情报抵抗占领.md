## 一、🔴 抵抗与顺从（Resistance & Compliance）

> **来源等级：【官方文档】** —— `resistance_compliance_modifiers/` 的字段注释

### 1.1 两个核心概念

| 概念 | 含义 |
|---|---|
| **Resistance（抵抗）** | 被占领地的反抗程度 |
| **Compliance（顺从）** | 被占领地的配合程度 |

**两者是"跷跷板"** —— 抵抗高则顺从低。

### 1.2 修正器结构（官方注释原文）

```txt
#modifier_id = {
#    tooltip = "bla_bla"                 # tooltip 用
#    icon = "GFX_bla_bla:1"              # 图标
#    icon_small = "GFX_bla_bla_small:1"  # 小图标（进度条用）
#
#    type = state_resistance_modifier    # 四种类型：
#         | core_resistance_modifier
#         | state_compliance_modifier
#         | core_compliance_modifier
#
#    threshold = 35                      # ⚠️ 百分比阈值才启用
#}
```

### 1.3 🔴 关键设计：按"阈值"分级启用

**真实例子**（【文件确证】）：

```txt
compliance_15 = {
    type = core_compliance_modifier
    icon = "GFX_occupation_compliance_modifier_strip:1"
    small_icon = "GFX_occupation_compliance_modifier_small_strip:1"
    threshold = 15                  # 顺从 ≥15% 才启用
    margin = 2                      # 容差
    state_modifier = {
        enemy_operative_detection_chance = 0.25
    }
}

compliance_25 = {
    type = core_compliance_modifier
    threshold = 25                  # 顺从 ≥25% 启用更强的
    ...
}
```

> 💡 **"阶梯式"而非"线性"** ——
> 顺从 15% 给一档奖励，25% 给更高一档。
> **让玩家有明确的"里程碑感"**。

### 1.4 四种作用域（重要区分）

| 类型 | 作用范围 |
|---|---|
| `state_resistance_modifier` | 州级抵抗 |
| `core_resistance_modifier` | 核心领土抵抗 |
| `state_compliance_modifier` | 州级顺从 |
| `core_compliance_modifier` | 核心领土顺从 |

**官方说明**：

> "for state modifiers, the scope will be the state, FROM/root will be the occupier
> and from from will be the occupied country"

**翻译**：州级修正器的作用域是州，`FROM/root` 是占领方，`from from` 是被占领国。

> 💡 **区分"州级"和"核心级"** ——
> 核心领土（自己的）和被占领土的规则不同。

## 二、🔴 占领法（Occupation Laws）

> **来源等级：【文件确证】** —— `common/occupation_laws/occupation_laws.txt`（17 KB）

HOI4 提供**多种占领策略**，各有取舍：

| 占领法 | 倾向 |
|---|---|
| 军事管制 | 抵抗低，但顺从也低 |
| 地方警察 | 平衡 |
| 温和占领 | 顺从涨得快，但抵抗也可能高 |
| 强制劳动 | 资源多，抵抗高 |

> ⚠️ **诚实说明**：我只确认了文件存在（17 KB），
> **没有逐条读**具体数值。以上是 HOI4 的通用认知（【社区】）。

**设计意图【推测】**：

```
占领不是"占了就完事"
而是要选"怎么管"  →  管法影响 抵抗/顺从/产出
```

> 💡 **这让"占领"变成一个持续的决策**，而不是一次性动作。

## 三、情报机构（Intelligence Agencies）

> **来源等级：【文件确证】** —— `common/intelligence_agencies/00_intelligence_agencies.txt`（8 KB）

HOI4 的情报系统有**独立机构**概念：

```
情报机构（Agency）
  ├─ 机构升级（intelligence_agency_upgrades）
  ├─ 特工（operative）
  └─ 任务（operative_mission / operative_operation）
```

**相关 AI token**（从 `ai_strategy` 看到）：

```
operative_mission       # AI 派特工做什么任务
operative_operation     # AI 做什么行动
```

> ⚠️ **对我们的适用性低** —— 春秋战国没有"情报机构"这个概念。
> **但"间谍/斥候"这个古老概念可以对应。**

## 四、自治领（Autonomous States）

> **来源等级：【文件确证】** —— `common/autonomous_states/`

HOI4 的占领地可以升级为**自治领**（傀儡国）：

```
被占领 → 傀儡国 → 自治领 → 独立
```

> 💡 **这和 CK3 的"附庸"、EU4 的"属国"是同一个思路** ——
> **占领地不是终点，可以逐步"扶正"。**

## 六、我们能借鉴什么

### 6.1 值得学的（按优先级）

| 借鉴点 | 来源 | 为什么好 |
|---|---|---|
| **🔴 阶梯式阈值奖励** | HOI4（15%/25%...） | 有里程碑感，比线性好 |
| **🔴 占领策略可选** | HOI4 占领法 | 让占领成为持续决策 |
| **抵抗/顺从双变量** | HOI4 | 比单一"同化进度"丰富 |
| **占领地可升级** | HOI4 自治领 | 逐步"扶正" |

### 6.2 🔴 最契合我们的：阶梯式阈值

**HOI4 的做法**（【文件确证】）：

```txt
compliance_15  → threshold = 15   # 顺从 15% 给一档
compliance_25  → threshold = 25   # 顺从 25% 给更高一档
```

**我们可以套用到**：

| 场景 | 阶梯 |
|---|---|
| 省份同化 | 25% / 50% / 75% / 100% 各给一档 |
| 核心化 | 类似 |
| 文化融合 | 类似 |

> 💡 **比"同化进度条慢慢涨"更有反馈感。**

### 6.3 ⚠️ 不能照搬的

| 为什么 |
|---|
| HOI4 是**二战占领**，绑死它的"州/核心领土"体系 |
| 它的"情报机构"我们不需要 |
| 数值必须重调 |
