## 二、🔴 战斗机制（我们最该学的）

> **来源等级：【文件确证】** —— `game/gameValues/GV_Battle.json`

### 2.1 完整战斗数值

```json
{
    "BATTLE_DEPLOYMENT_PHASE_TURNS": 2,          // 部署阶段回合数
    "BATTLE_CASUALTIES": 10,                     // 伤亡系数
    "BATTLE_MIN_BATTLE_WIDTH": 8,                // 最小战斗宽度
    "BATTLE_MAX_BATTLE_WIDTH": 24,               // 最大战斗宽度
    "BATTLE_SIDES_RATIO": 0.4,                   // 双方宽度比例

    "BATTLE_FULL_RETREAT_IF_MORALE_BELOW": 0.05, // 士气低于此值 → 全面撤退
    "BATTLE_MORALE_LOSS_MULTIPLIER": 1.5,        // 士气损失倍率

    "BATTLE_ARMY_DESTROYED_ROUND_ID": 10,        // 第几回合起可能全歼
    "BATTLE_ARMY_DESTROYED_IF_MANPOWER_PERC_BELOW": 0.1,  // 兵力低于 10% 可被全歼

    "BATTLE_MAX_DICE_ROLL": 8,                   // 骰子上限
    "BATTLE_MAX_DICE_ROLL_REGIMENT": 2,          // 每团骰子加成

    "BATTLE_WAR_SCORE_CASUALTIES": 30.0,         // 战斗伤亡给多少战争分
    "BATTLE_WAR_SCORE_MAX": 17.5,                // 单场战斗最多给多少

    "BATTLE_MIN_MORALE_VICTORIOUS_ARMY": 1.1,    // 胜方最低士气
    "BATTLE_MIN_MORALE_DEFEATED_ARMY": 0.75,     // 败方最低士气
}
```

### 2.2 🔴 关键洞察：**战斗有宽度限制**

```
BATTLE_MIN_BATTLE_WIDTH = 8
BATTLE_MAX_BATTLE_WIDTH = 24
BATTLE_SIDES_RATIO = 0.4
```

> 💡 **这直接解决了我们"人海碾压"的问题** ——
> 战斗宽度限制**同时参战的部队数**，兵力再多也只能排队上。
> **这正是 CK3 也有、而我们没有的机制。**

### 2.3 战斗有骰子（随机性）

```
BATTLE_MAX_DICE_ROLL = 8              # 基础骰子
BATTLE_MAX_DICE_ROLL_REGIMENT = 2     # 每团额外骰子
```

> 💡 骰子让**弱者有机会**，避免纯数值碾压的无聊。

### 2.4 战斗战术（4 种，带克制）

> **来源等级：【文件确证】** —— `GV_BattleTactics.json`

```json
{
    "BATTLE_TACTICS": [ "CarefulAdvance", "DefensiveHold", "StraightCharge", "FlankingManeuver" ],
    "BATTLE_TACTICS_ATTACK":  [ 0, -30,  35,  25 ],
    "BATTLE_TACTICS_DEFENSE": [ 0,  30, -45, -30 ]
}
```

| 战术 | 攻击加成 | 防御加成 |
|---|---:|---:|
| CarefulAdvance（谨慎推进） | 0 | 0 |
| DefensiveHold（防御固守） | **-30** | **+30** |
| StraightCharge（正面冲锋） | **+35** | **-45** |
| FlankingManeuver（侧翼机动） | **+25** | **-30** |

> 💡 **4 种战术形成攻防权衡矩阵** —— 攻得猛就守不住。
> **这是"用一张小表制造战术深度"的典范。**

### 2.5 与我们的对比

| 项 | AoH3 | 我们 |
|---|---|---|
| 战斗宽度 | ✅ 8~24，有上限 | ❌ **无**（人海碾压） |
| 骰子随机 | ✅ 有 | ❌ 无 |
| 战术选择 | ✅ 4 种，带克制 | ❌ 无 |
| 全歼条件 | 第 10 回合 + 兵力 <10% | 士气崩溃 |
| 伤亡公式 | **公开**（`BATTLE_CASUALTIES = 10`） | 我们自己定 |

## 九、玩家操作流程

### 9.1 打仗

```
1. 关系低于 -30 才能宣战
2. 军队相遇 → 自动开战
   - 前 2 回合是部署阶段
   - 战斗宽度限制参战部队（8~24）
   - 选战术（谨慎/固守/冲锋/侧翼）—— 攻防权衡
   - 骰子带来随机性
3. 士气低于 0.05 → 全面撤退
4. 第 10 回合起，兵力 <10% 可能被全歼
5. 打赢 → 得战争分（单场最多 17.5）
```

### 9.2 和约

```
1. 白和需 25 分，提要求需 90 分
2. 选条款：附庸 0.65 / 改宗 0.4 / 解放 0.125 / 要钱 0.04 ...
3. 割来的地：经济 60%、税收 60%、人力 75%
4. 和约后关系 -35
```

### 9.3 消化占领地

```
1. 占领 → 显示条纹色
2. 自动同化：每月 7.6%
3. 同化完成 → 变实色
4. 人口 <1000 的省直接全同化
```

## 十、设计意图 —— 为什么玩家会开心

> **来源等级：【推测】**

| 技巧 | 为什么这样设计 | 玩家感受 |
|---|---|---|
| **战斗宽度上限** | 防止人海碾压，逼玩家编队 | 「兵多不一定赢」 |
| **骰子** | 弱者有机会，避免无聊 | 「我这把运气好」 |
| **4 种战术** | 攻防权衡，有决策 | 「他冲锋了，我固守」 |
| **占领/同化两阶段** | 把"打下"和"消化"分开 | 「打下来了，但还没消化」 |
| **割地后惩罚** | 扩张有治理成本 | 「新地还得慢慢养」 |
| **破坏值** | 战争有长期代价 | 「打完这片地荒了」 |
| **自动白和** | 防僵尸战争 | 「打不动就自动停」 |
| **条款成本公开** | 谈判可预期 | 「我攒够 90 分就能要」 |

## 十一、我们能借鉴什么

### 11.1 🔴 最高价值：战斗宽度

**这是我们最该学的。**

| | 我们现状 | AoH3 |
|---|---|---|
| 战斗宽度 | ❌ **无** | ✅ 8~24 |
| 后果 | **1200 打 50 拖 12 天**（你报告的 bug） | 兵力再多也要排队 |

**我们那个"兵力悬殊"问题的根本解法，可能不是改伤亡公式，而是加战斗宽度。**
（当然，伤亡公式的问题也要修，两者独立。）

### 11.2 其他可借鉴点（按优先级）

| 借鉴点 | 数值（AoH3） | 对应我们 | 优先级 |
|---|---|---|---|
| **战斗宽度** | 8~24，比例 0.4 | `CombatRules` | 🔴 高 |
