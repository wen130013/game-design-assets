## 一、🔴 CK3 文化本体（层级结构）

> **来源等级：【文件确证】** —— `common/culture/cultures/00_berber.txt`

### 1.1 三层结构

```txt
文化组（berber_group）              ← 最外层
  ├─ graphical_cultures = {...}     # 图形风格
  ├─ mercenary_names = {...}        # 雇佣兵名字池
  │
  └─ 具体文化（iznagen）             ← 内层
       ├─ graphical_cultures        # 该文化的图形风格
       ├─ cadet_dynasty_names = {}   # 旁支王朝名（几十个）
       ├─ male_names = {}            # 男性名池
       ├─ color = { 0.55 0.36 0 }    # 文化颜色
       └─ ethnicities = {...}        # 民族特征
```

> 💡 **文化组 → 文化**两层，各自带命名库。
> **这对应春秋的"华夏 → 齐/楚/燕"这种层级。**

### 1.2 每个文化带什么数据

| 字段 | 作用 |
|---|---|
| `graphical_cultures` | 建筑/服装/纹章的图形风格 |
| `cadet_dynasty_names` | 旁支王朝名（**几十个**） |
| `male_names` / `female_names` | 名字池（**几百个**） |
| `color` | 文化在地图上的颜色 |
| `ethnicities` | 民族外貌特征 |
| `mercenary_names` | 雇佣兵名字 |

> 💡 **`cadet_dynasty_names`（旁支王朝名）** 是个有意思的设计 ——
> 一个家族分家后，旁支会从预设列表里取名。
> **让"分家"有历史感。**

## 二、🔴 CK3 文化革新机制（完整数值）

> **来源等级：【文件确证】** —— `00_defines.txt` 的 `NCulture` 段

### 2.1 🔴 进度公式（这是核心）

**原文注释**（直接引）：

```txt
# Chance (0..100) to advance with the innovation each month:
#   base + from exposure + from fascination
INNOVATION_PROGRESS_CHANCE_BASE = 5                          # 基础 5%
INNOVATION_PROGRESS_CHANCE_FROM_EXPOSURE = 40                # 有"接触"则 +40%
# from fascination = base + max(0, head learning skill - BASE) * PER_LEVEL
INNOVATION_PROGRESS_CHANCE_FROM_FASCINATION_BASE = 20        # 专注基础 20%
INNOVATION_PROGRESS_CHANCE_FROM_FASCINATION_HEAD_LEARNING_BASE = 0
INNOVATION_PROGRESS_CHANCE_FROM_FASCINATION_PER_LEARNING_LEVEL = 1   # 每点学识 +1%
INNOVATION_PROGRESS_CHANCE_FROM_FASCINATION_NO_HEAD_LEARNING = 10    # 无首领时按 10 算
```

**翻译成公式**：

```
每月推进概率 = 5%（基础）
             + 40%（若有"接触"）
             + 20% + 1% × 首领学识（若专注）
```

**最高可到 5 + 40 + 20 + N = 65%+ 每月。**

### 2.2 🔴 推进量公式

```txt
# If the random roll succeeds, the innovation will progress by:
#   base + from development + from eras ahead
INNOVATION_PROGRESS_GAIN_BASE = 0.3                              # 基础 0.3
INNOVATION_PROGRESS_GAIN_PER_AVERAGE_DEVELOPMENT_LEVEL = 0.02    # 每平均发展度 +0.02
INNOVATION_PROGRESS_GAIN_PER_ERA_AHEAD = 0.2                     # 每领先一个时代 +0.2
```

**翻译**：

```
成功时推进量 = 0.3
             + 0.02 × 平均发展度
             + 0.2 × 领先的时代数
```

> 💡 **"领先时代"有加成** —— 先进文化研究得更快（马太效应）。

### 2.3 🔴 时代推进

```txt
MINIMUM_INNOVATIONS_TO_NEXT_ERA = 0.5              # 需解锁 50% 革新才能进下一时代
ERA_PROGRESS_GAIN_BASE_MONTHLY = 0.1               # 每月基础 0.1%
ERA_PROGRESS_GAIN_MONTHLY_PER_AVERAGE_DEVELOPMENT_LEVEL = 0.05   # 每发展度 +0.05%
FIRST_ERA_START_YEAR = 476                         # 第一个时代起始年
```

**翻译**：

```
进入下一时代需要：解锁 50% 的当前时代革新
时代进度每月 = 0.1% + 0.05% × 平均发展度
```

> 💡 **"解锁 50% 才能进下一时代"** ——
> **不能跳时代，必须积累。**

### 2.4 🔴 接触（Exposure）—— 传播机制

```txt
INNOVATION_REGIONAL_PERCENTAGE = 0.1                # 区域占比 ≥10% 才有区域接触
INNOVATION_CULTURE_PERCENTAGE_IN_REGION = 0.4       # 文化占区域 ≥40% 才有接触
```

**机制**：

```
你的文化在某个区域占比 ≥40%
  → 能"接触"到该区域的革新
  → 推进概率 +40%
```

> 💡 **这是"技术传播"的模拟** ——
> **邻居有的技术，你能学到。**
> **对应春秋的"百家争鸣、互相影响"。**

### 2.5 文化差异的影响

```txt
COUNTY_OPINION_SAME_CULTURE = 0
COUNTY_OPINION_DIFFERENT_CULTURE = -5           # 同组不同文化 -5
COUNTY_OPINION_DIFFERENT_CULTURE_GROUP = -10    # 不同文化组 -10
COUNTY_CONTROL_LOSS_ON_HOSTILE_OWNER_CHANGE = 75   # 征服换手时控制度 -75
```

> 💡 **文化差异直接体现为"省份好感"惩罚** ——
> 同组 -5，异组 -10。
> **征服异族地盘，控制度会掉 75。**

## 三、EU4 文化（文化组 + 命名库）

> **来源等级：【文件确证】** —— `common/cultures/ME_cultures.txt`（46 KB）

### 3.1 结构

```txt
gaelic = {                          # 文化组
    graphical_culture = westerngfx

    cornish = {                     # 具体文化
        primary = CRN               # ⚠️ 关联国家 tag
        dynasty_names = { ... }     # 王朝名池
        male_names = { ... }        # 男名池（几百个）
    }
}
```

### 3.2 和 CK3 的对比

| 项 | CK3 | EU4 |
|---|---|---|
| 层级 | 文化组 → 文化 | 文化组 → 文化 |
| 命名库 | ✅ `male_names` / `cadet_dynasty_names` | ✅ `male_names` / `dynasty_names` |
| 关联国家 | — | ✅ **`primary = CRN`** |
| 图形风格 | ✅ `graphical_cultures` | ✅ `graphical_culture` |
| 颜色 | ✅ `color` | — |

> 💡 **EU4 多一个 `primary`（关联国家）** ——
> 文化直接绑到"主要国家"。
> **对应"齐文化 → 齐国"。**

### 3.3 文化在 EU4 里的作用

**从其他文件看到的**（【文件确证】）：

- 文化影响**税收、叛乱、接纳度**
- 文化组内**惩罚更小**
- 可以"**文化转化**"省份

## 七、我们能借鉴什么

### 7.1 值得学的（按优先级）

| 借鉴点 | 来源 | 为什么好 |
|---|---|---|
| **🔴 文化差异 = 省份好感惩罚** | CK3（-5/-10） | 让"征服异族"有代价 |
| **🔴 接触机制（技术传播）** | CK3（占比 ≥40%） | 契合"百家争鸣" |
| **🔴 命名库分层** | CK3/EU4 | 你已有 `Names.lua` |
| **旁支王朝名** | CK3 `cadet_dynasty_names` | 让"分家"有历史感 |
| **时代推进需解锁 50%** | CK3 | 不能跳时代 |
| **文化关联国家** | EU4 `primary` | 齐文化 → 齐国 |

### 7.2 🔴 最契合我们的：文化差异 = 省份惩罚

**CK3 的做法**（【文件确证】）：

```txt
COUNTY_OPINION_DIFFERENT_CULTURE = -5           # 同组不同文化
COUNTY_OPINION_DIFFERENT_CULTURE_GROUP = -10    # 不同文化组
COUNTY_CONTROL_LOSS_ON_HOSTILE_OWNER_CHANGE = 75   # 征服时控制度 -75
```

**为什么好**：

| 好处 | 说明 |
|---|---|
| **征服有代价** | 打下异族地盘，控制度掉 75 |
| **同组惩罚小** | 华夏内部（齐打楚）惩罚比打戎狄小 |
| **自然形成"文化圈"** | 同文化圈更容易整合 |

> 💡 **你的 `CultureSystem.lua` 有 135 行** —— 可以检查有没有这个机制。
