## 一、🔴 CK3 补给（完整数值）

> **来源等级：【文件确证】** —— `00_defines.txt` 的 `NMilitary` 段

### 1.1 补给是"0~100 的连续值"（不是有/无）

```txt
FULL_SUPPLY = 100                              # 满补给 = 100
SUPPLY_GAIN_BELOW_LIMIT = 20                   # 未超上限时，每次检查 +20
SUPPLY_LOSS_PER_SOLDIER_ABOVE_LIMIT = 0.001    # 每超 1 个兵，每次检查 -0.001
SUPPLY_LOSS_MINIMUM = 5                        # 最低损失
SUPPLY_LOSS_MAXIMUM = 10                       # 最高损失
```

**机制**：

```
军队补给值 0~100
  ├─ 未超省的补给上限  →  每次检查 +20（回补）
  └─ 超过省的补给上限  →  每次检查 -（0.001 × 超出人数），夹在 5~10
```

> 💡 **这是"连续值"而非"开关"** ——
> 补给慢慢掉，玩家有时间反应。

### 1.2 🔴 补给上限（省份能养多少兵）

```txt
BASE_SUPPLY_LIMIT = 2000            # 省份基础补给上限
SUPPLY_PER_DEVELOPMENT = 150        # 每点发展度 +150 上限
MINIMUM_SUPPLY_LIMIT = 1000         # 下限（永远不会更低）
```

**公式**：

```
省补给上限 = 2000 + 150 × 发展度
（最低 1000）
```

> 💡 **发展度越高，能养的兵越多** ——
> **这自然地把"经济"和"军事"连起来了。**

### 1.3 🔴 三档补给状态（带损耗）

```txt
SUPPLY_STATE_LEVELS = { 60  10  0 }      # 三档的分界
SUPPLY_STATE_NAMES = { SUPPLY_STATE_0 / _1 / _2 }
SUPPLY_STATE_ATTRITION = { 0.0  0.0  0.05 }
```

**解读**：

| 补给值 | 状态 | 损耗 |
|---|---|---|
| > 60 | STATE_0 | **0%** |
| 10 ~ 60 | STATE_1 | **0%** |
| 0 ~ 10 | STATE_2 | **5%** |

> 💡 **只有掉到 10 以下才开始损耗** ——
> **不是"一超上限就掉血"，而是有个缓冲带。**

### 1.4 领土加成（在自己地盘补给更好）

```txt
SUPPLY_OWN_REALM = 0.15         # 本国境内 +15%
SUPPLY_OWN_SUB_REALM = 0.3      # 次级领地 +30%
```

### 1.5 宽限期（刚集结/刚登陆不立刻掉补给）

```txt
NO_SUPPLY_LOSS_DAYS = 30        # 集结后 30 天不掉补给
ATTRITION_AFTER_DAYS = 30       # 登陆后 30 天才开始损耗
SUPPLY_LOSS_AT_SEA = 8          # 海上补给损失
```

> 💡 **"宽限期"很重要** ——
> 否则玩家每次集结军队都立刻掉补给，体验很差。

### 1.6 补员速度

```txt
REGIMENT_MONTHLY_REINFORCE_SPEED = 0.03       # 普通团每月补 3%
REGIMENT_MONTHLY_MAA_REINFORCE_SPEED = 0.1    # 常备军每月补 10%
```

> 💡 **常备军补员快 3 倍多** —— 精锐恢复得快。

### 1.7 其他相关

```txt
MOVEMENT_SPEED = 3                     # 基础移动速度
MOVEMENT_SPEED_BONUS_FRIENDLY_AREA = 0.2   # 友方区域 +20% 速度
GOLD_COST_PER_SOLDIER = 0.003          # 每兵金币维护费
RAID_ARMY_COST_MULT = 0.5              # 掠夺军维护费减半
COUNTY_MOVEMENT_ATTRITION_PERCENTAGE = 0.05  # 跨郡移动损耗
MINIMUM_COUNTY_MOVEMENT_ATTRITION = 100
MONTHLY_ATTRITION = 0.01               # 攻城/掠夺每月损耗 1%
```

## 二、HOI4 补给（对比）

> **来源等级：【文件确证】** —— `00_defines.lua` 的 `NMilitary` 段

**补给从哪来**：

```lua
SUPPLY_PORT_LEVEL_THROUGHPUT = 3,        -- 每个海军基地等级 3 补给吞吐
SUPPLY_ROUTE_RESOURCE_BONUS = 0.2,       -- 铁路/海路连接首都 → 资源 +20%
SUPPLY_CONVOY_FACTOR = 0.25,             -- 每份补给消耗多少运输船
SUPPLY_GRACE = 72,                       -- 部队自带 3 天补给
```

**断补给的后果**：

```lua
OUT_OF_SUPPLY_ATTRITION = 0.20,          -- 最大损耗 20%
OUT_OF_SUPPLY_SPEED = -0.8,              -- 速度 -80%
OUT_OF_SUPPLY_MORALE = -0.2,             -- 组织度恢复 -20%
SUPPLY_ORG_MAX_CAP = 0.35,               -- 组织度上限压到 35%
MAX_OUT_OF_SUPPLY_DAYS = 30,             -- 30 天达到最大惩罚
NON_CORE_SUPPLY_SPEED = -0.5,            -- 非核心领土补给更差
```

**断补给时的战斗力惩罚**：

```lua
COMBAT_SUPPLY_LACK_ATTACKER_ATTACK = -0.25,   -- 攻方攻击 -25%
COMBAT_SUPPLY_LACK_ATTACKER_DEFEND = -0.65,   -- 攻方防御 -65%
```

**损耗机制**：

```lua
ATTRITION_DAMAGE_ORG = 0.08,
ATTRITION_EQUIPMENT_LOSS_CHANCE = 0.1,
ATTRITION_WHILE_MOVING_FACTOR = 1,
```

> 💡 **HOI4 比 CK3 狠得多**：
> - 断补给防御 **-65%**（CK3 最多 5% 损耗）
> - 有速度/组织度惩罚
> - **攻方比守方惨**（-65% vs -25%）

## 五、我们能借鉴什么

### 5.1 🔴 核心思路（按优先级）

| 思路 | 来源 | 为什么好 |
|---|---|---|
| **🔴 补给是连续值，不是开关** | CK3（0~100） | 渐变，玩家有反应时间 |
| **🔴 补给上限挂钩发展度** | CK3（2000+150×发展） | 经济与军事自然联动 |
| **🔴 有缓冲带** | CK3（>10 才损耗） | 不是一超就掉血 |
| **🔴 宽限期** | CK3 30 天 / HOI4 72 小时 | 避免集结就掉补给 |
| **本国领土补给更好** | CK3 +15% | 本土作战优势 |
| **攻方比守方惨** | HOI4（-65% vs -25%） | 进攻需要补给 |
| **破坏值（战后恢复）** | AoH3 | 战争有长期代价 |

### 5.2 🔴 最契合我们的：补给上限挂钩发展度

**CK3 的公式**（【文件确证】）：

```
省补给上限 = 2000 + 150 × 发展度
```

**为什么好**：

| 好处 | 说明 |
|---|---|
| **经济军事联动** | 发展高的省能养更多兵 |
| **自然限制** | 穷省养不起大军 |
| **有下限** | `MINIMUM_SUPPLY_LIMIT = 1000` 保底 |

> 💡 **我们的省份有经济值** —— 可以直接挂钩。

### 5.3 具体数值参考（**不要直接搬**）

| 参数 | CK3 值 | HOI4 值 | 我们可考虑 |
|---|---|---|---|
| 补给上限 | 2000 + 150×发展 | 港口/铁路 | 按我们的省份数值调 |
| 超限损耗 | 5%（掉到 10 以下） | 20% | 介于两者 |
| 宽限期 | 30 天 | 72 小时（3 天） | 我们 `MOVE_DAYS = 3`，可参考 |
| 补员速度 | 3% / 10% 每月 | — | 需测 |
| 本国加成 | +15% | — | 可参考 |

> ⚠️ **参见 CK3 文档 §5.5 的实验**：数值必须配自己的体系重调。

### 5.4 ⚠️ 不能照搬的

| 为什么 |
|---|
| CK3 是**欧洲封建**，补给靠"郡的发展度" |
| HOI4 是**二战工业战**，补给靠铁路/港口网络 |
| 我们是**春秋战国**，应该靠"**粮道/驿站**" |
