### 1.2 🔴 法律结构（官方字段注释）

```txt
law_outlawed_dissent = {
    group = lawgroup_free_speech        # 属于哪个法律组
    icon = "gfx/interface/icons/law_icons/outlawed_dissent.dds"

    progressiveness = -50               # ⚠️ 进步度（-100 ~ +100）

    modifier = {                        # 采纳后的国家修正
        country_authority_add = 200
        country_bolster_attraction_factor = 0.5
        country_suppression_attraction_factor = -0.5
        country_tech_spread_mult = -0.15
        country_leverage_resistance_mult = 0.5
    }

    unlocking_technologies = {          # ⚠️ 解锁条件
        political_agitation
    }

    ai_enact_weight_modifier = {        # ⚠️ AI 采纳意愿
        value = 0
        if = {
            limit = { ai_has_enact_weight_modifier_journal_entries = yes }
            add = 750
        }
    }
}
```

### 1.3 🔴 言论自由组（完整的 4 档，【文件确证】）

| 法律 | 进步度 | 关键效果 | 解锁 |
|---|---:|---|---|
| `law_outlawed_dissent` | **-50** | 权威 +200、科技传播 **-15%** | `political_agitation` |
| `law_censorship` | 0 | 权威 +100、科技传播 -10% | `law_enforcement` |
| `law_right_of_assembly` | **+50** | 权威 +50 | — |
| `law_protected_speech` | **+100** | 科技传播 **+25%** | `human_rights` |

> 💡 **这是"完整的一组权衡"**：
> - 越保守 → 权威高，但**科技传播慢**
> - 越进步 → 科技传播快，但**权威低**
>
> **每档都有明确的代价和收益。**

### 1.4 关键设计点

**① `progressiveness`（进步度）**

```
-100 ~ +100
```

**这让"法律"有一个统一的坐标轴** —— 可以算"这个国家多进步"。

**② 法律要"科技解锁"**

```txt
unlocking_technologies = { political_agitation }
```

> 💡 **这解决了一个常见问题**：不能一上来就选最好的法律。

**③ `on_activate`（采纳时的副作用）**

```txt
law_protected_speech = {
    on_activate = {
        custom_tooltip = protected_speech_tt
        every_political_movement = {
            if = { limit = { is_being_bolstered = yes }  set_bolstering = no }
            else_if = { limit = { is_being_suppressed = yes }  set_suppression = no }
        }
    }
}
```

> 💡 **采纳"保护言论"→ 自动取消所有"压制"** —— 逻辑自洽。

**④ AI 采纳意愿是明文的**

```txt
ai_enact_weight_modifier = { value = 0  if = { ... add = 750 } }
```

### 2.2 🔴 奇观（Great Projects）

**文件**：`me_monuments.txt`（11.7 KB）

**结构**（从 EU4 通用认知，【社区】）：

```txt
great_project_key = {
    start / date            # 起始时间
    time                    # 建造时间
    build_cost              # 成本
    tier_0 .. tier_N        # ⚠️ 分级升级
    build_trigger / keep_trigger
}
```

> 💡 **"奇观分级升级"** ——
> 不是一次建完，而是**逐级投入**（tier_0 → tier_1 → ...）。
> **这比"一次性建完"更有养成感。**

**例子**（EU4 知名奇观）：
- 马耳他堡垒、凡尔赛宫、泰姬陵等
- 每级给不同的加成

## 四、我们能借鉴什么

### 4.1 值得学的（按优先级）

| 借鉴点 | 来源 | 为什么好 |
|---|---|---|
| **🔴 "进步度"坐标轴** | 维3 `progressiveness` | 用一根轴统一衡量所有政策倾向 |
| **🔴 每档都有代价** | 维3（言论自由 4 档） | 不是"越高级越好" |
| **法律要科技解锁** | 维3 | 防止一上来选最优 |
| **`on_activate` 副作用** | 维3 | 采纳政策有连锁反应 |
| **奇观逐级升级** | EU4 tier | 养成感 |

### 4.2 🔴 最契合我们的："进步度"坐标

**维3 的做法**（【文件确证】）：

```
law_outlawed_dissent    progressiveness = -50
law_censorship          progressiveness =   0
law_right_of_assembly   progressiveness = +50
law_protected_speech    progressiveness = +100
```

**一根轴，从 -100 到 +100。**

**为什么好**：

| 好处 | 说明 |
|---|---|
| **统一的坐标** | 能算"这个国家多进步" |
| **天然的权衡** | 越往一端，另一端就牺牲 |
| **AI 好判断** | 保守派/激进派的 AI 各有偏好 |

**我们可以做的**：给 `Policies.lua` 的政策加一个"倾向值"（如"守旧 ↔ 变法"），
然后：
- 守旧派 AI 偏好负值
- 变法派 AI 偏正值
- 玩家选政策时能看到"我整体偏哪边"

> 💡 **你 `Policies.lua` 里有"变法"** —— 这个概念天然就适合做成一跟轴。

### 4.3 另一个值得学的：每档都有代价

**维3 言论自由组的权衡**（【文件确证】）：

| 档位 | 权威 | 科技传播 |
|---|---:|---:|
| 禁止异见 | **+200** | **-15%** |
| 审查 | +100 | -10% |
| 集会权 | +50 | — |
| 保护言论 | — | **+25%** |

**越保守，权威越高但科技越慢。**

> 💡 **这正是你需要的** —— 你 `TODO.md` 说"经济杠杆交给政策卡"，
> 那**政策就必须有代价**，否则玩家永远选最优解。

### 4.4 ⚠️ 不能照搬的

| 为什么 |
|---|
| 维3 的 23 个领域绑死**工业社会**（劳工权利/福利/殖民） |
| 我们的政策应该是**春秋战国的**（变法/礼制/军功爵/井田） |
| EU4 奇观绑死它的历史建筑 |
