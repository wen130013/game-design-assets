## 一、🔴 CK3 部落时代革新（21 项，全是古代）

> **来源等级：【文件确证】** —— `00_tribal_innovations.txt`

### 1.1 🔴 时代名称（重要发现）

**CK3 的"部落时代"官方叫 `culture_era_tribal`，中文 loc 是「古典晚期」**：

```txt
culture_era_tribal:0 "Late Antiquity"
culture_era_tribal_desc:0 "The Late Antiquity Era ... represents the tumultous period
following the disappearance of the Western Roman Empire centralized power structure."
```

> 💡 **这正是"古代"** —— 罗马帝国崩溃后的时期。
> **对应我们的春秋战国，时代上完全契合。**

**CK3 的四个时代**（【文件确证】）：

| 时代 key | 英文 | 中文 |
|---|---|---|
| `culture_era_tribal` | Late Antiquity | **古典晚期** ← 古代 |
| `culture_era_early_medieval` | Early Medieval | 中世纪早期 |
| `culture_era_high_medieval` | High Medieval | 中世纪盛期 |
| `culture_era_late_medieval` | Late Medieval | 中世纪晚期 |

### 1.6 🔴 三大设计要点

**① 科技是"文化"的，不是"国家"的**

（详见 `08-文化宗教科技.md`）

**② 每项科技都"解锁具体东西"**

| 类型 | 数量 | 例子 |
|---|---:|---|
| 解锁兵种 | 5 | 投石机、重步兵、战象、骆驼骑兵 |

> 💡 **21 项里只有 3 项是纯数值** ——
> **大部分是"解锁新玩法"。**

**③ 进度公式**（【文件确证】—— 详见 `08-文化宗教科技.md`）

```
每月推进概率 = 5% + 40%（有接触）+ 20% + 1%×首领学识
成功时推进量 = 0.3 + 0.02×平均发展度 + 0.2×领先时代数
```

```json
{

    "RESEARCH_MAINTENANCE_COST": 0.15,
    "RESEARCH_BUILDING_COST_PER_RESEARCH_POINT": 0.5,
    "MAX_RESEARCH_BASE": 20,                              // 研发上限 20

```

**配合三档研发投入**（详见 `17-经济系统.md`）：

```json
"RESEARCH_LEVEL_RESEARCH": [-0.75,  0,   0.25],
"RESEARCH_LEVEL_COST":     [-0.75,  0,   0.5]
```

| 档位 | 研发 | 成本 |
|---|---:|---:|
| 低 | **-75%** | **-75%** |
| 中 | 0 | 0 |
| 高 | **+25%** | **+50%** |

> 💡 **研发有上限（20）** + **三档投入** —— 简单但完整。

| `artillery.txt` | 21 KB |
| ... 共 15 个 | |

**内容（机枪/坦克/飞机）完全不适用。**

### 3.2 🔴 但"组织方式"值得学

**HOI4 的科技结构**（【文件确证】）：

```txt
technologies = {
    basic_machine_tools = {
        production_factory_max_efficiency_factor = 0.1     # 效果

        # 🔴 前置关系（树状！）
        path = {
            leads_to_tech = improved_machine_tools
            research_cost_coeff = 1
        }
        path = {
            leads_to_tech = concentrated_industry
            research_cost_coeff = 1
        }
        path = {
            leads_to_tech = dispersed_industry          # ⚠️ 分叉！
            research_cost_coeff = 1
        }

        research_cost = 1.5          # 研究成本
        start_year = 1936            # ⚠️ 起始年份
        folder = {                   # ⚠️ 在科技树上的位置
            name = industry_folder
            position = { x = 0 y = 0 }
        }
        ai_will_do = { factor = 50 } # AI 权重
        categories = { industry  cat_production }
    }
}
```

### 3.3 🔴 四个可借鉴的设计

**① `path` / `leads_to_tech` —— 树状前置**

```txt
basic_machine_tools
  ├─→ improved_machine_tools
  ├─→ concentrated_industry     ← 分叉
  └─→ dispersed_industry        ← 分叉
```

**一个科技可以通向多个后继**（分叉）。

**② `research_cost_coeff` —— 分支成本**

```txt
path = { leads_to_tech = X  research_cost_coeff = 1 }
```

**同一前置，不同分支可以有不同成本。**

**③ `folder` + `position = { x, y }` —— 树上有坐标**

```txt
folder = {
    name = industry_folder
    position = { x = 0 y = 0 }
}
```

> 💡 **科技树是"可视化布局"的** —— 每个科技有 x/y 坐标。
> **你 `TechPanel.lua`（598 行）可能也需要这个。**

**④ `start_year` —— 年代限制**

```txt
start_year = 1936
```

**科技有"最早出现年份"** —— 不能提前研究。

### 3.4 科技常量

```lua
MAX_SUBTECHS = 3,                      -- 一个科技最多 3 个子科技
BASE_RESEARCH_POINTS_SAVED = 30.0,     -- 每个槽位可存的研究点
BASE_YEAR_AHEAD_PENALTY_FACTOR = 2,    -- 提前研究的惩罚系数
BASE_TECH_COST = 100,                  -- 基础研究成本
MAX_TECH_SHARING_BONUS = 0.5,          -- 科技共享最大加成
MIN_RESEARCH_SPEED = 0.1               -- 研究速度下限
```

> 💡 **`BASE_YEAR_AHEAD_PENALTY_FACTOR`（提前研究惩罚）** ——
> 研究"还没到时候"的科技要付代价。
> **这比"年份锁死"更灵活。**

### 6.3 🔴 最该检查的：你的科技是"数值"还是"解锁"


**你可以对照检查 `Techs.lua`**：
- 如果大部分是"+5% 伤害"这类 → 可以考虑改成"解锁新兵种/新政策"
