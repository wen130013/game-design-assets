## 【下一步】兵种系统

### 设计约定（2026-09-19 用户拍板）
- **4 大类**：步兵 / 弓兵 / 骑兵 / 攻城（结构照 CK3）
- **兵种并列，不分一阶二阶三阶**（用户："所有兵种不分什么一阶二阶三阶"）
- **科技强化"按类"**：一条科技强化一整个类（该类下所有兵种都受益），不是单兵种强化
- **不做文化专属兵种**（用户："没有文化兵种"）
- **强化条目要少**：每类 1~2 条（用户："不要弄太多科技强化，不然太占地方"）
- **研究范围**：春秋战国 → 宋朝（已完成裁剪）

### 兵种清单（实况：已实现，攻城类未做）
| 类 | 兵种 | 解锁科技 | 状态 |
|---|---|---|---|
| 步兵 | 轻步兵 / 重步兵 / 长枪兵 | 开局 / 青铜兵 / ironarms | ✅ 已实现 |
| 弓兵 | 弓手 / 弩兵 | 开局 / stirrup | ✅ 已实现 |
| 骑兵 | 轻骑兵 / 重骑兵 / 战车兵 | cavalry / stirrup / chariot | ✅ 已实现 |

- 相克环（照 CK3）：散兵 → 重步兵 → 长枪兵 → 骑兵 → 弓兵 → 散兵
- 属性维度（照 CK3）：伤害 / 坚韧 / 追击 / 掩护 / 维护费
- 数据源：`scripts/data/Units.lua`（数值整套照抄 CK3 Men-at-Arms）

### 多兵种混编（2026-09-24 新做）
- **规则**：一支军队可有多个兵种；比例由**玩家征召时决定**（CK3 口径：比例在买常备军时定死，
  将军不决定比例，补员只按原比例补）
- **存储**：`prov.unitMix = { light_inf = 0.8, archer = 0.2 }`（比例，和为 1）；
  `garrison` 仍是**总兵力纯数字**，兵种明细是派生值 → 调军/战斗/解散/存档 40 多处不用改
- **已接**：征召加权、调军带走比例、并入按人数合并、战斗逐兵种算战力+相克、
  追击/掩护、维护费（按全国构成）、AI 征兵、存档
- ⚠️ **仅跑过数据层验证，未实机打过一仗** —— 战斗结算公式被改过，验收时重点看这个

## 调研结论（备查）

### 参考游戏机制
- **CK3 兵种**：4 大类（步兵/弓兵/骑兵/攻城），类内并列不升级，有相克环；
  属性 = 伤害/坚韧/追击/掩护/维护费；编制人数表达精锐度（步兵 100、重骑 50、攻城 10）
- **CK3 军队两层**：征召兵（只有一种农民步兵，玩家不能选）+ 常备军 MAA
  （**玩家购买时自选兵种，比例由玩家定死**）。将军**不决定比例**，只定统兵上限。
  补员：MAA 每月补 10%，**各团按自己原比例独立补**，只在自家领地
- **CK3 科技**：叫 Innovations，按**文化**自动推进（非玩家点研究），时代递进解锁兵种
- **CK3 战斗**：3 天一轮、士气主导（士气崩 = 败退主因）、一场仗 3~7 天
- **CK3 战争迷雾**：**原版没有**（要装 mod），走外交关系/间谍网的情报模型
- **EU4 迷雾**：Terra Incognita，接壤后每月随机概率探索（约 3~5 年揭开）；
  **迷雾里也能看到敌军位置**（位置可见、细节不可见）
- **AoH3 迷雾**：开局设置可选三档强度，中途不能改；只有自己省 + 瞭望塔范围可见，
  **境外敌军完全看不见**
- **AoH3 兵种**：7 大类 × 时代升级链（石器→…→未来），前线/侧翼/支援三线布阵
- **我们的差距**：士气损失太慢（4/天）→ 战斗拖到 10~17 天。调到 8~10/天即可拿到 CK3 节奏
