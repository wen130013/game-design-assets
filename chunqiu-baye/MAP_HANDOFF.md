## 技术要点（新对话必须知道）

- **游戏地图 = 一张 ID 位图**（每像素编码区域ID，RGB: R=0, G=id>>8, B=id&0xFF）+ 省份数据（id/name/center/polygon）
- **渲染管线**：成品图 `map_political.png` → 切瓦片 `tiles/map_TX_TY.png`（1024px）→ `MapRenderer` 分块渲染（只画视口内的瓦片）
- **关键文件**：
  - `scripts/map/MapRenderer.lua`（渲染/点击/缩放，瓦片渲染）
  - `scripts/data/Geography.lua`（地图尺寸 MAP_W/H、BITMAP_W/H、BITMAP_SCALE、BITMAP_PATH）
  - `scripts/data/Provinces.lua`（加载 WorldProvinces_N.lua 省份数据）
  - `scripts/data/WorldProvinces_N.lua`（当前 Natural Earth 省份数据，将替换为 EU4 数据）
  - `gen_world_map.py`、`gen_world_final.py`、`gen_tiles.py`、`crop_oceania.py`、`fix_base_map.py`（生成脚本，可参考/改造）
  - `backup/`（各类备份）
- **EU4 数据转换流程**（要做的）：
  1. 从 EU4 安装目录 `map/` 取 `provinces.bmp` + `definition.csv`
  2. 用 definition.csv 建立"像素颜色→省份ID"映射，把 provinces.bmp 转成游戏的 ID 位图
  3. 处理投影（EU4 是自定义投影，需确认范围是否欧亚非、如何对齐）
  4. 生成省份数据（id/name/center/polygon，polygon 可从位图提取或从 EU4 数据）
  5. 生成成品图 + 瓦片
  6. 调好颜色（底图感 + 势力色）
