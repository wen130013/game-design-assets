## 现状一句话

**两个地图包，同一份源数据，一张裁过一张没裁：**

| 包 id | 显示名 | 范围 | 画布 | 省份 | 状态 |
|---|---|---|---|---|---|
| `eu4` | **旧大陆** | 经度 -31.5°..180°（211.5°） | 5640×3840 | 2457 | ✅ 主线，已上线用着 |
| `world` | **新世界** | 经度 -180°..180°（**全球 360°**） | 9600×3840 | 3359 | ✅ 可用（**无势力**，纯看地图；选国页点「观察」进） |

两包**共用同一个投影**，只差一个裁剪常数：
`eu4.lua` 的 `CROP_X0 = 495`（裁掉西经 31.5° 以西）／`world.lua` 的 `CROP_X0 = 0`（不裁）。
投影的 x 是**纯线性**的，所以同一块地在两包里**形状一个像素不差，只是整体平移 +3960**
（实测 2348/2349 个唯一名省份精确 (+3960, 0)，唯一例外差 1px 是栅格化舍入）。

# 地图包架构（现状）

```lua
-- scripts/data/MapPack.lua
MapPack.registry = {
    eu4   = require("data.mappacks.eu4"),     -- 旧大陆
    world = require("data.mappacks.world"),   -- 新世界
}
MapPack.activeId = GameConfig.MapPack or "eu4"   -- 默认包
```

**每个包自己声明**（`scripts/data/mappacks/<id>.lua`）：

| 字段 | 含义 | eu4 | world |
|---|---|---|---|
| `MAP_W / MAP_H` | **逻辑**坐标系（省份多边形按它走） | 5640×3840 | 9600×3840 |
| `BITMAP_W / BITMAP_H` | **位图**尺寸 | 5640×3840 | 9600×3840 |
| `BITMAP_SCALE` | 逻辑→位图的换算（`px = lx / BITMAP_SCALE`） | 1.0 | 1.0 |
| `WHOLE_IMAGE_PATH` / `_HALF_PATH` | **整图底图（主线）**：≥1.0 倍用全图，低倍率用半图 | ✅ | ✅ |
| `NEUTRAL_WHOLE_IMAGE_PATH` / `_HALF` | 编辑器"无主底图" | ✅ | ✅ |
| `PROVINCE_ID_PATH` | 省 ID 位图（R=0, G=id>>8, B=id&0xFF） | ✅ | ✅ |
| `PROVINCE_LUT_PATH` | 显示色 LUT（4096×1） | ✅ | ✅ |
| `PROVINCE_FILES` | 省份数据分片（`require` 用） | `Provinces_1..5` | `Provinces_1..8` |
| `INITIAL_ZOOM / MIN_ZOOM / MAX_ZOOM` | 倍率范围（从包里读；换包由 `refreshMapConstants()` 重算） | 0.16 / 0.05 / 4 | 0.094 / 0.05 / 4 |
| `project(lon, lat)` | 经纬度 → 逻辑像素 | 见下 | 见下 |

**投影（两包只差一个常数）**：
```lua
-- 等距圆柱；纬度范围是源数据标定的 78.54°N..42.03°S（不是 ±90°）
local x = ((lon + 180.0) / 360.0 * 1200.0 - CROP_X0) * 8   -- eu4: 495   world: 0
local y = (78.54 - lat) * 3.981 * 8
```

**关键换算（答"图做大/缩小 + 提倍率"那类问题用）**：
- 屏幕上看着多大 = **每度像素 × 倍率**
- eu4 = 5640/211.5° = **26.67 px/°**；world = 9600/360° = **26.67 px/°（一样）**
- **倍率只能把已有像素拉大，不增加细节**；要让新加的部分和原来一样清楚，**只能真把图做大**

# 技术要点（新对话必须知道）

- **游戏地图 = 一张 ID 位图**（每像素编码区域 id）+ 省份数据（id/name/center/polygon/area/isWasteland）
- **渲染主线 = 整图**（不是瓦片）：`MapRenderer` 里 `if MapPack.WHOLE_IMAGE_PATH then 整图 else 瓦片回退`
  → **world 包没生成瓦片**（`--no-tiles`），因为整图配了就永远走整图
- **关键文件**：
  - `scripts/map/MapRenderer.lua` —— 渲染/点击/缩放/相机（模块级常量由 `refreshMapConstants()` 重算）
  - `scripts/data/MapPack.lua` —— 地图包注册表 + `switchTo`（换包四件套）
  - `scripts/data/mappacks/<id>.lua` —— 单包配置
  - `scripts/data/Geography.lua` —— 尺寸转发（已改**元表现取**，随包走）
  - `scripts/data/Provinces.lua` —— 省份数据分片（`reload()` 按当前包重载）
  - `scripts/data/Factions.lua` —— 势力数据（`FACTION_SOURCES` **按包提供**：eu4 有、world 无）
  - `scripts/ui/CountrySelect.lua` —— 选国页，左边那列地图列表（未开局可换图 / 局内禁用）
- **换包四件套（`MapPack.switchTo`）**：① 字段 → ② 省份 → ③ 势力 → ④ 渲染常量。
  ⚠️ 以后再加"加载时抓包"的东西（数据表 / 模块级常量），**必须加进 switchTo**，否则就是新的"半套切换"
  （排查：`grep -n '^local [A-Za-z_]* *= *(Geography|MapPack|Provinces)\.' scripts/`）

# 生成脚本（已参数化，一份脚本出两个包）

```bash
# 生成【旧大陆】（⚠️ 会覆盖手工改过的 eu4.lua：显示名/整图路径/MAX_ZOOM=4，别乱跑）

        --desc "全球地图（含美洲/大洋洲，基于欧陆风云4省份划分）" --no-tiles --no-desert
python3 gen_neutral_tiles.py --pack world --no-tiles

# 可选参数：--pack / --crop / --keep-oceania / --name / --desc / --no-tiles / --no-desert
#   --crop 0    = 不裁（全球 360°）      --crop 495 = 欧亚非（旧大陆）
#   --keep-oceania = 保留澳大利亚/新西兰（做全球图必须加）
#   --no-desert    = 地图上不画沙漠：废土省用无主米色 + 省界全画（新世界必须加，2026-09-15）

# ⚠️ 重生成 world 会覆盖 world.lua 的手工改动（WHOLE_IMAGE_* 指向无主版、MAX_ZOOM=4、
#    各项拍板注释）—— 先备份 world.lua + 省数据，生成后恢复；
#    省数据本身重新生成后**逐字节一致**（可 diff 验证），**存档不受影响**
```

**生成器输出**（`gen_eu4_map.py`）：省份数据分片、省 ID 位图、成品图、LUT、配置 `.lua`、（可选）瓦片
**`gen_neutral_tiles.py`**：无主底图（整图 + 半图）；**它出的 `.lua` 不含整图路径**，
`WHOLE_IMAGE_PATH / WHOLE_IMAGE_HALF_PATH / NEUTRAL_*` 需要**手工补进包配置**。

⚠️ **9600 宽的真机风险**：本地软件渲染（llvmpipe）能过，但**很多手机 GPU 单张纹理上限是 4096/8192**，
9600 > 8192 可能加载失败；显存也从 82.6 MB 涨到 **140.6 MB**。
**兜底方案**：把生成时的 `SCALE` 从 8 降到 6 → 7200×2880、79 MB、每度 20px（清晰度 75%）。
