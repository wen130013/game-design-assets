# 地形系统方案（讨论定稿 → 待实施）

> 2026-09-22 与用户讨论定稿。**本文只描述方案，未动代码。**
> 讨论背景：地形视图里内陆省显示"沿海"、同国地形纯随机无地理逻辑（两次截图实证）。

---

## 一、决定事项（用户拍板）

1. **地形共 11 种**，命名照 CK3 简化，删掉别扭的（洪泛平原→平原、沙漠山地→沙漠）。
2. **"沿海"从地形表摘除**，改成独立的 **临海标记（isCoastal）**——CK3 也是这么分的：
   - 地形 terrain = 地里长出来的（按男爵领/省份地理指定）
   - 沿海 coastal = 布尔判定（挨不挨着海），作用：造船/登陆/港口/海上贸易
3. **不设"不可通行"地形**——我们的领土全部可以行军，EU4 的 `impassable_mountains` 一律归丘陵。
4. 加成（战斗/补给/移动）**照 CK3 的数值档位抄**。

## 二、数据现状（重要：地形数据我们手上没有）

| 来源 | 内容 | 有地形字段吗 |
|---|---|---|
| `data/eu4/eu4_provinces.svg` | MapChart EU4 边界（3360 省裁剪 2457） | ❌ 只有边界 |
| `scripts/data/mappacks/eu4/Provinces_*.lua` | 已转好的省份数据 | ❌ 只有 `centerLon/centerLat/area/isWasteland/neighbors/polygon` |
| EU4/CK3 游戏本体的 terrain 数据 | 没有（无游戏安装，网络受限） | ❌ |

**所以"直接抄 EU4 逐省地形"做不到。** 但省份数据里有 **逐省经纬度**，够用了——
改用 **「按真实地理规则离线推算 + 固化」**：规则本身就是照现实地理写的（山脉在哪、沙漠在哪是常识），
排除了随机，且每个省都可以人工修正。

**推荐策略**：中国区（玩家主要活动区，lon 100~125 / lat 18~48）规则做细；世界其他区域按纬度带粗分即可。

## 四、地形怎么定（离线推算规则）

输入：`centerLon / centerLat / area / isWasteland / 是否临海`。**规则分层，先特殊后默认**：

**1. 纬度带（最高优先，全球通用）**
- `lat ≥ 66`（北极圈）→ **冻土**
- `55 ≤ lat < 66` → **针叶林**（西伯利亚、北欧、加拿大）

**2. 沙漠带 → 沙漠**
- 撒哈拉 `lon -17~35, lat 15~30`｜阿拉伯 `35~60, 12~32`｜伊朗中部 `52~62, 28~36`
- 卡拉库姆/克孜勒库姆 `55~67, 36~44`｜塔克拉玛干 `76~90, 36~41`｜戈壁 `90~115, 37~45`

**3. 山脉锚点 → 山地**（坐标框列表，中国区优先做细）
- 太行 `112~115, 35~41`｜燕山 `115~120, 40~43`｜秦岭 `105~112, 33~35`｜贺兰/六盘 `104~107, 35~39`
- 祁连 `95~103, 36~40`｜天山 `75~90, 41~45`｜昆仑/青藏 `75~102, 28~38`｜横断 `98~103, 24~32`
- 兴都库什/帕米尔 `68~75, 34~38`｜喜马拉雅 `78~95, 27~31`｜阿尔泰 `85~92, 46~52`
- 高加索 `40~50, 40~44`｜扎格罗斯 `45~58, 27~38`｜阿尔卑斯 `5~15, 44~48`｜喀尔巴阡 `20~27, 44~49`
- 乌拉尔 `58~62, 50~68`｜斯堪的纳维亚 `5~20, 58~70`
- （山脉带边缘 +1~2° 缓冲 → **丘陵**，避免山脉"一刀切"成一根线）

**4. 高原 → 丘陵**：黄土高原 `105~113, 34~40`（青藏归山地带）

**5. 草原带 → 草原**
- 蒙古高原 `88~120, 42~52`｜中亚草原 `45~80, 42~52`｜黑海-里海草原（乌克兰）`25~50, 44~52`

**6. 丛林 → 丛林**
- 中南半岛 `95~110, 8~23`｜印度南部/西高止 `73~85, 8~20`｜南洋群岛 `95~140, -10~8`

**7. 森林 → 森林**
- 东北 `120~135, 40~53`｜云贵/西南 `98~110, 22~30`｜欧洲中部 `5~30, 45~55`｜印度东部 `80~88, 18~25`

**8. 沼泽 → 沼泽**
- 长江中下游 `110~122, 28~33`｜湄公河三角洲 `104~107, 9~12`｜恒河三角洲 `88~92, 21~24`
- 尼罗河三角洲 `29~32, 30~32`｜两河下游 `44~49, 29~33`

**9. 农田 → 农田**
- 华北平原 `113~120, 32~40`｜长江下游 `117~122, 29~33`｜关中 `106~110, 33~35`
- 印度河/恒河平原 `70~90, 20~32`｜两河上游 `38~45, 30~36`｜尼罗河谷 `29~33, 22~30`｜地中海沿岸

**10. 默认兜底**：临海 → 平原；内陆 → 平原（低纬）/ 草原（`40 ≤ lat < 55`）

> 规则表落成一张 Python/Lua 表，跑一次 → 写死进省份数据（或独立 `Terrain_*.lua` 覆盖表）。
> `isWasteland=true` 的省照旧（荒地不是领土，可以再单独给个"荒地"显示，不进 11 种地形）。

## 五、临海（isCoastal）怎么算

- 数据源：`image/eu4/province_id.png`（省 ID 位图）
- 算法：逐省扫像素 → 只要有一个像素的 8 邻域是"非省像素"（海/图外）→ `isCoastal = true`
- 离线跑一次，固化到省份数据（`isCoastal=true`）
- 显示：省份面板 → `地形: 平原 · 临海`（两个维度分开展示，同 CK3）
- 玩法（以后接）：造船/登陆、港口建筑、海上贸易/劫掠

## 七、实施步骤（等用户点头后执行）

1. **`scripts/data/Terrains.lua`**（新）：11 种定义（名字/颜色/产出/补给/防御/行军）
2. **离线脚本**（`gen_terrain.py`，新）：读 `Provinces_*.lua` 经纬度 → 规则推算地形 + 扫位图算临海
   → 输出 `scripts/data/mappacks/eu4/Terrain_*.lua`（省 id → terrain/isCoastal 覆盖表）
3. **`scripts/core/GameState.lua:230-246`**：删掉 zone 权重随机抽取 → 读固化地形（保留无数据时兜底）
4. **系统适配**：
   - `EconomySystem.TERRAIN_BONUS`（6 → 11 种）
   - `MilitarySystem.TERRAIN_DEFENSE` / `SUPPLY_TERRAIN_BASE`（11 种）
   - `MapRenderer` 地形配色（12 旧名 → 11 新名）
   - `GameUI` 地形视图说明文案 + 省份面板加"· 临海"
   - `Geography.terrainStats`（8 → 11 种产出/人口区间）
5. **抽查修正**：导出「省名 → 地形」清单，人工过一遍中国区
6. **回归**：LSP 检查 → build → 预览验证地形视图
